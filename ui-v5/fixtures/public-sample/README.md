# Публичный fixture для ревью

Это намеренно урезанный, но реальный набор данных для проверки проекта. В нём
три настоящих кадра и полный набор извлечённых артефактов для каждого кадра:
исходные и производные изображения, маски, landmarks, UV-текстура, `mesh.obj`,
`mesh.mtl`, `*.npz`, CSV и JSON-метаданные. Также приложены все 236 строк
Stage2, в которых участвует хотя бы один из этих кадров.

Полный локальный анализ намного больше и остаётся на съёмном диске. В GitHub
намеренно не публикуются веса моделей, полный Stage1, полный Stage2 и локальные
результаты запусков. Поэтому этот набор предназначен для анализа ошибок,
контрактов и недоработок, а не является полной копией исследования.

`tools/build_public_fixture.py` пересобирает fixture из локальных Stage1/Stage2.
