## ЧАСТЬ 1: КАК ПРОВЕРИТЬ ТЕОРИИ ИЗ СМИ ДЛЯ ШИРОКОЙ АУДИТОРИИ

За десятилетия в СМИ и блогосфере накопились десятки популярных теорий о возможных двойниках Владимира Путина — их условно называют «Удмурт», «Василич», «Банкетный» и др. Журналисты-расследователи собрали более **90 конкретных анатомических признаков**, по которым их якобы можно отличить (форма скул, угол челюсти, разрез глаз, ширина переносицы).

Как научная система работает с этими теориями, не нарушая собственной объективности?

### Изолированный карантинный режим (Quarantine Policy)
Главное правило проекта: **частные гипотезы никогда не смешиваются с основным слепым анализом**. Все 90+ гипотез помещены в специальный карантинный раздел (`private_hypothesis_seed`). Данные со страницы проверки гипотез запрещено экспортировать в публичные отчеты или использовать для подгонки байесовских вероятностей.

### Компенсация смещения старой разметки (Shift Bias Calibration)
Ранее журналисты формулировали свои теории на основе старых измерений с не до конца выровненными ключевыми точками. Без коррекции новый сверхточный датасет `3DDFA_v3` покажет системное смещение. 
В интерфейс встроены ползунки **`Shift Bias X/Y/Z`** (сдвиг по осям в миллиметрах) и **`Range Tolerance`** (расширение/сужение допуска). Они позволяют в реальном времени скорректировать базовую линию каждой гипотезы и увидеть точный процент ее подтверждения реальным датасетом.

## ЧАСТЬ 2: ПОЛНЫЙ СПИСОК РЕАЛИЗОВАННЫХ ФУНКЦИЙ БЭКЕНДА (100% ОХВАТ КОДА)

Ниже приведен технический реестр модулей директории `app6/private_hypothesis_seed/`, реализующих валидацию гипотез.

### 1. Модуль `app6/private_hypothesis_seed/` (Защищенный реестр гипотез)
- **`load_legacy_hypothesis_ledger() -> list[HypothesisRecord]`**  
  Считывает 90+ записей из файла `legacy_hypothesis_ledger.jsonl`. Каждая запись содержит целевую сущность (`putin`, `udmurt`, `vasilich`), анатомическую зону из атласа 21 зоны и ожидаемый интервал значений.
- **`apply_shift_bias_calibration(record: HypothesisRecord, shift_x: float, shift_y: float, shift_z: float, tolerance: float) -> HypothesisRecord`**  
  Применяет линейный вектор коррекции к ожидаемым порогам гипотезы, компенсируя погрешность ранних ручных разметок.

### 2. Модуль `app6/api/server.py` (Изоляция результатов)
- **`@app.get("/api/v1/hypotheses/retest_results")`**  
  Возвращает результаты тестирования гипотез. Эндпоинт снабжен жестким заголовком-водяным знаком `X-Forensic-Scope: INTERNAL_TEST_ONLY`, предотвращающим попадание этих данных в выгружаемый публичный отчет `09_RESULTS_REGISTER.md`.

## ЧАСТЬ 3: ИНТЕГРАЦИЯ С ИНТЕРФЕЙСОМ UI v5

В рабочей станции `DEEPUTIN UI v5.0` этот функционал реализован на странице **«Валидация гипотез (99 баллов)» (`/hypotheses`)**:
- Яркий предупреждающий баннер подтверждает изолированный карантинный статус раздела;
- 90+ гипотез разбиты на 3 крупные блока: *«putin vs остальные»*, *«udmurt vs vasilich»* и *«попарные признаки»*;
- Панель слайдеров `Shift Bias X/Y/Z` позволяет мгновенно калибровать сдвиг;
- Плитки гипотез подсвечиваются светло-зеленым оверлеем (20% прозрачности) при подтверждении ($>80\%$) или светло-красным при опровержении ($<40\%$).
