## 2. ПРИОРИТЕТЫ И ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ (EXECUTION ORDER)

Для эффективной реализации задачи выполняются в следующей очередности:
1. **Первый приоритет (День 1 — Поток А):** задачи **A1, A2, A3, A4, A5** — подключение к серверу `app6/api/server.py` и проверка кэша.
2. **Второй приоритет (День 2 — Поток Б):** задачи **B1, B2, B3** — виртуализация таблиц/лент и фоновый Web Worker.
3. **Третий приоритет (День 3 — Поток В):** задачи **C1, C2, C3, C4** — бинарная загрузка 3D-топологии BFM в Canvas-вьюер.
4. **Четвертый приоритет (День 4 — Потоки Г и Д):** задачи **D1–D3** (PDF/Immutable Bundle) и **E1–E3** (E2E-тесты и декларация 100%).
