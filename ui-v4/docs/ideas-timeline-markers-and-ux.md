# Таймлайн: 20 идей маркеров и визуальных элементов + 15 идей UI/UX

Два списка для следующих итераций интерфейса. Первый — про **отображение
данных на таймлайне** (маркеры, иконки, формы элементов). Второй — про
**общий UX**. Все идеи привязаны к текущему коду (ui-v4): таймлайн уже имеет
миниатюры, треки метрик, anomaly-полосу, playhead, A/B-режим и зум. Балл —
польза для расследования × наглядность × простота. S — часы, M — 1–2 дня.

### 1. Кольцо качества вокруг миниатюры · 98

Круглое кольцо вокруг фото, цвет — по градиенту качества (зелёный → жёлтый →
красный), толщина — величина. Минимальные смещения = зелёное тонкое кольцо,
плохие фото = красное толстое.

**Зачем.** Сейчас качество видно только в треках; при 9 панелях глаз не
успевает. Кольцо читается мгновенно на любой миниатюре.

**Данные.** `photo.quality` уже есть в каждой строке таймлайна.

### 2. Бейдж ракурса на миниатюре · 96

В углу миниатюры — маленькая пиктограмма бина: ◀ профиль влево, ◐ полупрофиль,
◉ анфас, ◑, ▶. 9 уникальных глифов. При включённой одной панели бейдж лишний,
но при режиме «Все фото» (без разбивки на панели) он незаменим.

### 3. Маркер конфликта дат · 95

Над фото с `date_provenance_status=conflict` — двуцветный значок «⚖ 2 даты»:
имя файла vs EXIF. Ховер — карточка: filename date, EXIF date, delta, источники
конфликта.

**Зачем.** Датировка — фундамент хронологии (D-002); конфликт должен быть
заметен раньше, чем начнётся анализ формы.

### 4. Цепь дубликатов · 94

Near-duplicate фото соединяются скобкой/дугой с цепочкой «🔗 ×3». Клик по дуге
подсвечивает все копии.

**Зачем.** Дубликаты искажают и выборку, и пары; видимая цепь показывает,
сколько «уникальных событий» реально стоит за группой фото.

### 5. Флаги change-point Stage 2 · 94

Вертикальный флажок ⚑ над датой, где активный run обнаружил change point
(`change_points.json`). Цвет — по статусу (красный — persistent, жёлтый —
candidate). Флаг кликабелен — открывает карточку пары A→B со значениями.

**Зачем.** Это главный результат Stage 2; на таймлайне он должен «кричать», а
не прятаться в отчёте.

### 6. Границы эпох на линейке · 93

На общей линейке — цветные сегменты эпох (1999–2004, 2005–2010, …) с
подписями и вертикальными разделителями. Уже есть `era_meta` с цветами.

### 7. Затенение пропусков покрытия · 93

Интервалы без фото в бине — затенённая полоса с подписью «нет данных 2004–2006».
Клик — карточка «в этот период в бине нет ни одного фото — выводы ограничены».

**Зачем.** Пустые места — зоны слабой доказательности; они должны быть видны
так же ясно, как сами фото.

### 8. Ореол поза-аутлайера · 92

Фото, отсечённые pose-outlier фильтром или выбивающиеся по yaw/pitch (MAD),
получают фиолетовое свечение и пунктирную рамку, даже если ещё не исключены.

### 9. Иконка отсутствующего артефакта · 92

Пиктограммы в углу миниатюры: «∅ mesh», «∅ uv», «∅ ldm» — если файла нет
(из inventory issues). Ховер — список отсутствующих файлов.

### 10. Полоса плотности по годам · 91

Под линейкой — мини-гистограмма: высота столбика = число фото в году.
Клик по столбику — фильтр таймлайна на этот год. Мгновенно видно, где
данных много, а где «дыры».

### 11. Маркеры выражения · 91

Пиктограмма 😊 (smile_detected) или 😮 (jaw_open_detected) на фото. В ховере —
значения corner_lift_ioc / jaw_open_ratio. Мимика — главный искажающий фактор
формы; она должна бросаться в глаза до сравнения.

### 12. Значок калибровочной поддержки · 90

В заголовке панели бина — «cal ✓ 7/7» или «cal ✗ 2/7» (число персон
калибровки с кадрами в этом бине). Серая панель = выводы по этому ракурсу
опираются на слабую калибровку.

### 13. Звезда пересечения с архивом зацепок · 90

Фото, чьи даты пересекаются с датами приоритетных leads из архива
(`lead_registry.json`), получают ★. Клик — карточка: какие старые зацепки
касаются этой даты.

### 14. Коннектор A→B · 89

В A/B-режиме выбранные фото соединяются стрелкой-дугой (A — синяя, B —
оранжевая) поперёк таймлайна. Сразу видно хронологический размах сравнения
(5 месяцев или 14 лет).

### 15. Сектор confidence · 89

Дополнительный сектор в кольце качества: заполненная часть круга =
confidence. Два параметра в одном элементе.

### 16. Индикатор силы мимики · 88

Тонкая полоска под миниатюрой с интенсивностью expression_magnitude
(градиент серый → жёлтый → красный). Отличается от маркера-смайла: показывает
степень, а не факт.

### 17. Бейдж «×N» кластера одной даты · 88

Если в бине несколько фото одной даты (same_date_sequence), миниатюры получают
общий бейдж «×3» и рамку-группу. Ховер — список id группы.

### 18. Иконка неполного провенанса · 87

Фото с `source_provenance_status != provided` — значок «◔» (частичный источник)
или «◌» (неизвестный). В ховере — цепочка источника.

### 19. Playhead-плеер · 87

Кнопка «▶ Показ» — playhead автоматически едет по годам (скорость 1 год/сек),
подсвечивая текущее фото в каждой панели. «Кино» по хронологии: скачки формы
заметны даже при быстром прогоне. Пауза — клик.

### 20. Мини-спарклайн под миниатюрой · 86

Под каждой миниатюрой — 20px мини-график выбранной метрики (quality или
landmark shift), построенный от соседних фото. Позволяет видеть тренд прямо в
ленте, без включения отдельного трека.

### 1. Undo/redo для всех действий · 98

Ctrl+Z / Ctrl+Shift+Z отменяют: движение ползунков фильтров, ручную курацию
профиля, A/B-выбор, настройки виджетов, переключение панелей. История —
в памяти сессии (до перезагрузки), в журнал профиля пишется только финальное
состояние.

**Зачем.** Случайное движение ползунка сейчас безвозвратно меняет выборку.
Отмена — базовая гигиена любого инструмента с ползунками.

### 2. Rich-тултипы над фото · 97

Ховер над миниатюрой — карточка: дата, ракурс, quality/confidence, pose-углы,
провенанс-статус, 2–3 аномалии, мини-превью face_crop и кнопки действий
(«Открыть», «Сравнить как A», «Исключить»). Появляется за 250 мс, не мешает
скроллу.

### 3. Контекстное меню (правый клик) · 96

Единая система контекстных меню: фото — «Photo Lab / как A / как B /
исключить из выборки / копировать ID / скриншот»; трек — «показать только его /
убрать / настройки порога»; панель — «только этот ракурс / скрыть». Ускоряет
рутину в 2–3 раза и разгружает панели инструментов.

### 4. Фокус-режим · 95

Клавиша F (или кнопка) — сайдбар и панели скрываются, таймлайн на весь экран.
Вторая F — возврат. Для долгих сессий сравнения и для скриншотов.

### 5. Тосты о фоновых задачах · 94

Уголок экрана с уведомлениями: «Run run_… завершён (225 пар)», «Отчёт готов»,
«Экспорт скачан», «Калибровка обновлена». Не перебивают работу, уходят сами
через 6 сек, клик открывает результат.

### 6. Скелетоны и прогрессивная загрузка · 93

Вместо «Загрузка…» — скелетон-заглушки формы карточек; миниатюры появляются
с blur-эффектом по мере загрузки (lazy). Большой датасет (сотни фото) не
выглядит «мёртвым» во время чтения.

### 7. Пресеты рабочего места · 92

Кнопки-пресеты: «1 ракурс», «3 ракурса + quality», «9 ракурсов + shift»,
«Провенанс», «Мой рабочий набор». Пресет сохраняет панели, треки, зум и
фильтры. Уже есть пресеты 1/3/9 — расширить их конфигурацией.

### 8. Статус-бар пайплайна · 92

Постоянная строка внизу: Stage 1 (N фото) · профиль (имя, N включено) ·
последний run (статус, время) · калибровка (7/7) · версия кода. Всегда видно,
на каких данных сейчас работаешь.

### 9. Табличные цифры · 91

`font-variant-numeric: tabular-nums` для всех чисел в треках, тултипах и
карточках. Значения не «прыгают» при обновлении — критично при сравнении
цифр на бегу.

### 10. Цветобезопасная палитра · 90

Проверка всех цветов на дейтеранопию (самый частый тип дальтонизма): градиент
смещений дублируется размером/формой точек (кольца, радиусы), статусы —
иконками, не только цветом. Легенда в шапке.

### 11. Пустые состояния с действием · 90

«Нет фото в этом ракурсе» → «Открыть Data Manager → Запустить извлечение»;
«Нет Stage 2» → «Run Manager → Запустить прогон (оценка пар: 225)». Каждое
пустое состояние — кнопка следующего шага, а не тупик.

### 12. Переключатель RU/EN · 89

Полный перевод интерфейса; forensic-термины (LDM, pose bin, calibration)
остаются английскими в обоих языках. Пригодится для внешних рецензентов и
публикаций.

### 13. Экран горячих клавиш «?» + палитра команд · 89

«?» открывает сводку хоткеев; Ctrl+K — палитра команд («фото…», «дата…»,
«ракурс frontal», «трек LDM106», «запустить Stage 2»). Частично уже есть
клавиатурная навигация — довести до единого слоя.

### 14. Режим презентации · 88

Кнопка «Презентация»: крупный шрифт, чистый фон, без служебных панелей, одна
панель на экран. Для показа редакции/рецензенту с проектора. Скриншоты из
этого режима сразу пригодны для документов.

### 15. Тёмная/светлая тема · 87

Переключатель темы (CSS-переменные уже есть). Светлая тема — для печатных
версий отчётов и скриншотов в текстовые документы; тёмная — основная рабочая.

## Рекомендуемый порядок

**Быстрые победы на таймлайне (1–2 дня):** №1 кольцо качества → №2 бейдж
ракурса → №3 конфликт дат → №6 границы эпох → №11 смайлы → №15 сектор
confidence. Таймлайн становится «читаемым» без треков.

**Глубина (2–3 дня):** №7 пропуски → №10 плотность → №8 ореол позы → №14
коннектор A→B → №5 флаги change-point (требует чтения активного run).

**UX (после маркеров):** №4 фокус-режим → №5 тосты → №1 undo/redo → №2
rich-тултипы → №3 контекстные меню.

Маркеры реализуются поверх текущих миниатюр (`pure-thumb`) и anomaly-полосы —
отдельный слой отрисовки, существующие элементы не ломаются.
