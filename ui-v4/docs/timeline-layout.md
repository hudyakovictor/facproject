# Timeline v4.2 — multi-pose workspace

- По умолчанию открыт один ракурс `frontal`.
- Кнопка «Добавить ракурс» добавляет второй, третий и последующие независимые таймлайны, расположенные вертикально один под другим.
- Все ракурсы используют общую временную шкалу, playhead, zoom и горизонтальный scroll.
- Для каждого ракурса независимо выбираются pose bin, минимальное качество, режим «только с аномалиями» и любой набор метрик.
- Доступны quality, confidence, bone, orbit, chin, jaw, cheek, symmetry, yaw, pitch, roll и texture diagnostics.
- Аномалии отображаются в отдельной полосе иконок; они не рисуются поверх фотографии.
- На миниатюре отображается только изображение — без даты, текста, оценок и флагов.
- Размер миниатюры непрерывно меняется от 30×30 px на fit-zoom до 150×150 px при максимальном приближении.
- Алгоритм collision lanes раскладывает близкие по времени фотографии по дополнительным строкам и гарантирует отсутствие наложений.
- Double click открывает полную Photo Lab страницу выбранного кадра.
