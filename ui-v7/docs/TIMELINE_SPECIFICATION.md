## ЧАСТЬ 2: Техническое задание для UI-v7 таймлайна

### 2.1. Концепция

UI-v7 таймлайн — это forensic workstation timeline, вдохновленный Adobe Premiere Pro, но адаптированный для анализа фотоархива с учетом специфики исследования:

- **Timeline-based навигация** — основное взаимодействие через временную шкалу
- **Многослойное представление** — каждый слой (track) для определенного типа данных
- **Интерактивный scrubbing** — перемещение по хронологии с мгновенным откликом
- **Контекстная детализация** — от общего обзора к деталям конкретного кадра

### 2.3. Основные компоненты таймлайна

#### 2.3.1. Timeline Surface (Основная поверхность)

**Функциональность:**
- Canvas 2D рендеринг с использованием d3-scale для осей
- Поддержка 1700+ фото с виртуализацией
- Плавный зум с сохранением позиции курсора
- Перетаскивание (pan) с инерцией
- Масштабирование временной шкалы (годы → месяцы → дни)

**Визуальные элементы:**
- Временная ось с адаптивными метками
- Вертикальная линия текущего положения (playhead)
- Фоновая сетка с привязкой к временным меткам
- Визуализация плотности фотографий

#### 2.3.2. Track System (Система дорожек)

**Типы дорожек:**

1. **Фото-дорожка (Photo Track)**
   - Отображает миниатюры фотографий
   - Цветовая индикация качества
   - Рамки для аномалий
   - Группировка по ракурсам

2. **Метрики качества (Quality Metrics Track)**
   - quality score
   - alignment quality
   - pose confidence
   - detection confidence

3. **Метрики текстуры (Texture Metrics Track)**
   - skin quality score
   - skin authenticity score (ОБЩАЯ МЕТРИКА КОЖИ)
   - silicone probability
   - filler probability
   - wrinkle density
   - subsurface scattering

4. **Геометрические метрики (Geometry Metrics Track)**
   - bone score
   - orbit depth
   - chin projection
   - jaw width
   - cheek prominence
   - symmetry index

5. **PCA компоненты (PCA Track)**
   - p0 (главная компонента формы)
   - p1
   - p2

6. **Калиброванные z-оценки (Calibration Track)**
   - z-orbit depth
   - z-chin projection
   - z-jaw width
   - z-cheek

7. **Поза и ракурс (Pose Track)**
   - yaw angle
   - pitch angle
   - roll angle
   - residual yaw

8. **Хронологические метрики (Chronology Track)**
   - expression magnitude
   - jaw open degree
   - visual age
   - calendar age

9. **LDM Shape Difference Track (НОВЫЙ)**
   - Общая метрика различия формы лица
   - Рассчитывается из LDM106/LDM134 chronology данных
   - Показывает сходство/различие между соседними фото

10. **Anomaly Track (Дорожка аномалий)**
    - Визуализация всех типов аномалий
    - Цветовое кодирование по типу
    - Размер маркера по значимости

#### 2.3.3. Event System (Система событий)

**Типы событий:**

1. **Photo Events** — отдельные фотографии
2. **Anomaly Events** — выявленные аномалии
3. **Change Point Events** — точки перелома
4. **Calibration Events** — калибровочные точки
5. **User Annotation Events** — пользовательские заметки

  // Текстура кожи
  skinQuality: number;
  skinAuthenticity: number; // ОБЩАЯ МЕТРИКА КОЖИ
  siliconeProb: number;
  fillerProb: number;
  wrinkleDensity: number;
  subsurface: number;
  
  // Геометрия
  boneScore: number;
  orbit: number;
  chin: number;
  jaw: number;
  cheek: number;
  symmetry: number;
  
  // PCA
  p0: number;
  p1: number;
  p2: number;
  
  // Калиброванные z-оценки
  zOrbitDepth: number;
  zChinProj: number;
  zJawWidth: number;
  zCheek: number;
  
  // Хронология
  expressionMagnitude: number;
  jawOpenDegree: number;
  visualAge: number;
  calendarAge: number;
  
  // LDM Shape Difference (НОВОЕ)
  ldmShapeDifference: number; // Общая метрика различия формы

#### 2.5.2. Описание фильтров

**Quality Filters:**
- **Frame Quality** — общее качество кадра (0-1)
- **Alignment Quality** — качество выравнивания (0-1)
- **Pose Confidence** — уверенность определения позы (0-1)
- **Detection Confidence** — уверенность детекции лица (0-1)

**Texture Filters:**
- **Skin Quality** — качество кожи (0-1)
- **Skin Authenticity** — аутентичность кожи (ОБЩАЯ МЕТРИКА)
- **Silicone Probability** — вероятность силикона (0-1)
- **Filler Probability** — вероятность филлера (0-1)

**Geometry Filters:**
- **Bone Score** — костная основа (0-1)
- **Symmetry** — симметрия (0-1)
- **Z-Orbit Depth** — z-оценка глубины глазницы
- **Z-Chin Projection** — z-оценка выступа подбородка

**Pose Filters:**
- **Yaw Range** — диапазон рыскания
- **Pitch Range** — диапазон тангажа
- **Roll Range** — диапазон крена
- **Residual Yaw** — остаточный yaw

**Chronology Filters:**
- **Date Range** — диапазон дат
- **Visual Age** — визуальный возраст
- **Calendar Age** — календарный возраст
- **Expression Magnitude** — величина выражения

**Anomaly Filters:**
- Toggle для каждого типа аномалий
- Возможность фильтрации по значимости

**LDM Filters (NEW):**
- **Shape Difference** — общая метрика различия формы
- **LDM106 Difference** — различие по 106 точкам
- **LDM134 Difference** — различие по 134 точкам

### 2.9. Производительность

6. **Memoization** — кэширование результатов вычислений
7. **Debouncing** — отложенное обновление при быстрых изменениях
