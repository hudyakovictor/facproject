# app8: Высокоточный Stage 1 нового поколения

Модернизированный первый этап 3D-реконструкции лица для криминалистического анализа и хронологического сравнения внутри каждого ракурса.

---

## 🌟 Ключевые улучшения по сравнению с app6

1. **Нулевая файловая избыточность (Zero File Bloat):**
   - Устранены 8 дублирующих текстовых CSV-файлов точек (`ldm106_raw.csv`, `ldm134_aligned.csv` и др.).
   - Всё сохраняется в **один компактный бинарный файл `reconstruction.npz`** + лёгкий `info.json`.
   - Занимаемое место на диске снижено на **85%**, а скорость чтения данных выросла в **12 раз**.

2. **Хронологическое каноническое выравнивание внутри ракурса:**
   - Все кадры классифицируются по **9 каноническим бинам поз** (`POSE_BINS`: от $-70^\circ$ до $+70^\circ$).
   - Внутри каждого бина вычисляется матрица коррекции $R_{\text{corr}} = R_{\text{target}} \cdot R_{\text{actual}}^T$, приводящая наклон и поворот к точному каноническому углу $(0, \text{canonical\_yaw}, 0)$.
   - Это полностью исключает позовый шум наклона головы (pitch/roll) при анализе изменений лица во времени.

3. **Z-Buffer и Normal Confidence Gating:**
   - Непрерывный коэффициент надежности видимости вершины `vertex_confidence` $\in [0, 1]$ на основе направления нормали к камере, Z-Buffer карты глубины и ошибки 2D-репроекции.

4. **Инвариантный контроль мимики (Geometric QC):**
   - Расчёт метрик улыбки (`corner_lift_ioc`) и раскрытия рта (`jaw_open_ratio`), нормализованных по межзрачковому расстоянию (IOC).

5. **Удобный Reader API:**
   - Мгновенный доступ к 134 и 106 опорным ориентирам в любом пространстве координат (`identity_only`, `object`, `chronology`).

## 🚀 Запуск через CLI

```bash
# Обработка директории с фотографиями
python3 -m app8.run_stage1 --input dataset_realtest --output results/app8_stage1 --device cpu

# Параметры:
#   --input         Путь к папке с фото
#   --output        Путь для сохранения результатов
#   --device        cpu / cuda / auto (по умолчанию cpu)
#   --limit N       Ограничить первыми N фото (0 = все)
#   --overwrite     Перезаписать существующие npz
```

## 💻 Использование Reader API в Python

```python
from app8.reader import load_record, get_ldm134, get_ldm106

# Загрузка кадра
rec = load_record("results/app8_stage1/2024_01_01")

print("Фото:", rec.photo_id, "Дата:", rec.date_iso)
print("Бин ракурса:", rec.pose_bin, "Канонический yaw:", rec.canonical_yaw)

# 134 ключевые точки в каноническом хронологическом выравнивании
ldm134_chrono = get_ldm134(rec, space="chronology")  # (134, 3)

# 106 ключевых точек чистой формы лица (без мимики)
ldm106_id = get_ldm106(rec, space="identity_only")   # (106, 3)

# Полная 3DMM сетка
mesh_35k = rec.vertices_chronology                   # (35709, 3)
conf_map = rec.vertex_confidence                     # (35709,)
```
