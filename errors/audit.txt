Про доказательность

    Событие съёмки как единица независимости: автокластеризация фото по (дата ±1 день, источник, ракурс, схожесть фона/освещения). Одна сессия у фотографа — одно свидетельство, сколько бы кадров ни было.
    Дневник наблюдения: каждый переход статуса (слабый → усиленный → устойчивый → оспорен → опровергнут) записывается с датой, парой-причиной и правилом, которое сработало.
    Раздельные каналы: геометрия (кость) и текстура (кожа) — два независимых наблюдения на одну зону, никогда не сливаются в один балл.
    Скачок vs тренд: простой тест монотонности по хронологии. Постепенное монотонное изменение — «возрастная динамика, низкий интерес»; ступенька между соседними эпохами — «требует объяснения».
    Симметрия: если левая и правая парные зоны меняются одинаково по знаку и величине — это, скорее всего, возраст/вес, интерес понижается. Асимметричное изменение — интерес повышается.
    Проверка альтернатив на каждое наблюдение: возраст, вес (сопутствующие мягкие ткани), мимика, качество кадра, ракурс, освещение, ретушь — каждая альтернатива получает статус «исключена / возможна / не проверялась».
    Тест перестановки дат: отчёт собирается второй раз со случайно перемешанными датами. Наблюдения, которые «выживают» без реальной хронологии, — артефакт метода, а не факт.
    Ловушки-контроли внутри отчёта: пары «кадр — его рекроп» вшиваются в каждую эпоху; если система на них видит «изменение» — вся эпоха получает стоп-флаг.
    Зеркальные дубли: детекция горизонтально отражённых перепубликаций. Без этого любое асимметричное наблюдение (п. 5) ненадёжно.
    Тень ретуши: индикаторы (аномальная гладкость при высоком разрешении, отсутствие микрорельефа) → зона исключается из текстурного канала, фото помечается.

Про структуру отчёта
11. Базовая линия только из ≥3 фото и ≥2 ракурсов; иначе baseline_weak, и все последующие уровни уверенности принудительно понижаются на ступень.
12. Матрица покрытия эпоха × ракурс на каждой странице эпохи — показывает слепые пятна («в 2006 нет ни одного правого профиля»).
13. Карта пробелов и «что закроет вопрос» генерируется автоматически: недостающий (ракурс × эпоха × независимый источник) на каждое открытое наблюдение.
14. Маршрутный лист для редакции: упорядоченный по приоритету список ручных проверок, сквозной по всем эпохам.
15. Блок «что мы НЕ можем сказать» обязателен на каждой странице.
16. Наблюдение ≠ интерпретация: система печатает только наблюдения; поле «интерпретация» пустое и подписано «заполняет редакция».
17. Словарь зон для журналистов: каждая зона имеет обиходное имя и одну фразу «почему это важно / насколько стабильно в жизни».
18. Стоп-правило эпохи: если >30% пар эпохи не прошли ворота ракурса или качества — страница эпохи помечается «выводы недопустимы», а не просто «мало данных».
19. Трассируемость: каждое утверждение несёт список photo_id/pair_id; редакция может за минуту найти исходные файлы.
20. Порог качества фото (межзрачковое расстояние в пикселях, размытость, артефакты сжатия): ниже порога фото — только контекст, не доказательство.

Про процесс
21. Fail-closed сборка: нет весов, нет контрольных сумм, негативный контроль не пройден — генератор отказывается собирать публикационную версию и собирает черновик с водяным знаком в каждом блоке.
22. Human-in-the-loop: файл editorial_marks.json, где редакция помечает наблюдения accepted/rejected/needs_source; при следующей сборке это учитывается и логируется.
23. Версионирование отчёта: любая правка датировки/добавление фото → новая версия и diff «какие наблюдения изменили статус».
24. Правила статусов — только явные пороги, никакого ML: журналист может проверить статус наблюдения вручную по таблице правил.
25. Бюджет сравнений на эпоху: поправка Бенджамини–Хохберга применяется по эпохе, и число проверенных сравнений печатается рядом с каждым наблюдением.

DATE_RE = re.compile(r"(?P<y>19\d{2}|20\d{2})_(?P<m>\d{2})_(?P<d>\d{2})")

def date_from_filename(name: str) -> Optional[str]:
    """Единственный авторитет датировки — имя файла ГГГГ_ММ_ДД (сохранено)."""
    m = DATE_RE.search(name)
    if not m:
        return None
    y, mo, d = int(m["y"]), int(m["m"]), int(m["d"])
    if not (1 <= mo <= 12 and 1 <= d <= 31):
        return None
    return f"{y:04d}-{mo:02d}-{d:02d}"

    "medium": "средняя — ≥2 независимых события, ≥2 ракурса ИЛИ ≥2 источника, альтернативы частично исключены",
    "high":   "высокая — ≥3 независимых даты, ≥2 ракурса И ≥2 источника, сильный эффект, альтернативы исключены, пережил перестановку дат",
}
CONF_ORDER = ["none", "low", "medium", "high"]

def downgrade(conf: str) -> str:
    i = CONF_ORDER.index(conf)
    return CONF_ORDER[max(0, i - 1)]

RETOUCH_LIMIT = 0.7  # ADAPT: калибровать на известных ретушированных фото

def grade_photo(p: PhotoRecord) -> PhotoRecord:
    """evidence — можно строить выводы; context — только упоминание; rejected — не использовать."""
    p.finalize_date()
    reasons = []
    if p.date_status != "ok":
        reasons.append(f"дата:{p.date_status}")
    if p.ipd_px < MIN_IPD_PX:
        reasons.append(f"низкое разрешение лица ({p.ipd_px:.0f}px)")
    if p.blur > MAX_BLUR_SCORE:
        reasons.append("размытие")
    if p.jpeg_q < MIN_JPEG_Q:
        reasons.append("артефакты сжатия")
    if p.date_status == "missing" or p.ipd_px < MIN_IPD_PX * 0.5:
        p.quality_status = "rejected"
    elif reasons:
        p.quality_status = "context"
    else:
        p.quality_status = "evidence"
    p.quality_reasons = reasons  # динамический атрибут для рендера
    return p

def effective_visible_zones(p: PhotoRecord) -> set:
    z = set(p.visible_zones)
    if p.mouth_open:
        z -= MOUTH_EXCLUDE          # сохранено: исключение при открытом рте
    if p.retouch_score >= RETOUCH_LIMIT:
        p.retouch_flag = True       # дополнение №10: текстурный канал зон не используется
    return z

def collapse_duplicates(photos: dict, near_dup_pairs: list, mirror_pairs: list):
    """
    near_dup_pairs: [(a,b)] из stage1 (рекропы/перепубликации) — ADAPT
    mirror_pairs:   [(a,b)] горизонтально отражённые (дополнение №9) — ADAPT
    Побайтовые дубли (равный checksum) схлопываются здесь же.
    """
    parent = {pid: pid for pid in photos}
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]; x = parent[x]
        return x
    def union(a, b):
        ra, rb = find(a), find(b)
        if ra != rb: parent[rb] = ra
    by_sum = {}
    for pid, p in photos.items():
        by_sum.setdefault(p.checksum, []).append(pid)
    for ids in by_sum.values():
        for other in ids[1:]:
            union(ids[0], other)
    for a, b in near_dup_pairs:
        union(a, b)
    for a, b in mirror_pairs:
        union(a, b)
        photos[b].mirror_of = a
    for pid, p in photos.items():
        p.dup_group = f"dup_{find(pid)}"
    return photos

def gate_pair(pair: PairRecord, photos: dict) -> PairRecord:
    a, b = photos[pair.photo_a], photos[pair.photo_b]
    reasons = []
    if a.dup_group == b.dup_group:
        pair.gate_status = "dup"; pair.gate_reasons = ["один и тот же кадр/перепубликация"]
        return pair
    if a.pose_bin != b.pose_bin or a.pose_bin != pair.pose_bin:
        reasons.append("разные ракурсы")
    if pair.delta_deg > HARD_DELTA_LIMIT:
        reasons.append(f"расхождение углов {pair.delta_deg:.1f}° > {HARD_DELTA_LIMIT}°")
    elif pair.delta_deg > MAX_DELTA_DEG.get(pair.pose_bin, 0):
        reasons.append(f"расхождение углов {pair.delta_deg:.1f}° > допуска бина")
    if reasons:
        pair.gate_status = "pose_fail"; pair.gate_reasons = reasons; return pair
    if "ok" not in (a.date_status, b.date_status) or a.date_status != b.date_status:
        pair.gate_status = "date_fail"; pair.gate_reasons = ["конфликт/отсутствие даты"]; return pair
    if a.quality_status == "rejected" or b.quality_status == "rejected":
        pair.gate_status = "quality_fail"; pair.gate_reasons = ["фото отклонено по качеству"]; return pair
    # пересечение видимых зон (сохранено): всё вне — вычёркиваем
    vis = effective_visible_zones(a) & effective_visible_zones(b)
    pair.zone_deltas = {z: d for z, d in pair.zone_deltas.items() if z in vis}
    # текстурный канал недоступен, если хотя бы одно фото с ретушью
    if getattr(a, "retouch_flag", False) or getattr(b, "retouch_flag", False):
        for d in pair.zone_deltas.values():
            d.tex_z, d.tex_p = None, None
        reasons.append("текстура исключена: признаки ретуши")
    # диагностический режим при малом числе точек (сохранено)
    for z, d in pair.zone_deltas.items():
        if d.n_landmarks < MIN_CALIBRATED_LANDMARKS:
            d.diagnostic_only = True
    pair.gate_status = "pass"
    pair.gate_reasons = reasons
    pair.evidence_grade = "evidence" if (a.quality_status == b.quality_status == "evidence") else "context"
    return pair

from datetime import date
from itertools import combinations

def _d(s): 
    y, m, d = map(int, s.split("-")); return date(y, m, d)

def assign_shoot_events(photos: dict, background_sim: dict | None = None):
    """
    Дополнение №1. Событие съёмки = один источник, даты в пределах ±1 дня,
    один ракурс-бин (или схожий фон, если stage1 даёт background_sim[(a,b)] в [0,1]).
    Пары внутри события НЕ являются независимыми свидетельствами.
    """
    ids = [p for p in photos.values() if p.date_status == "ok"]
    ids.sort(key=lambda p: (p.source, p.date))
    parent = {p.photo_id: p.photo_id for p in ids}
    def find(x):
        while parent[x] != x: parent[x] = parent[parent[x]]; x = parent[x]
        return x
    for a, b in combinations(ids, 2):
        if a.source != b.source: continue
        if abs((_d(a.date) - _d(b.date)).days) > 1: continue
        same_bg = background_sim.get((a.photo_id, b.photo_id), 0) > 0.8 if background_sim else False
        if a.pose_bin == b.pose_bin or same_bg or a.dup_group == b.dup_group:
            ra, rb = find(a.photo_id), find(b.photo_id)
            if ra != rb: parent[rb] = ra
    for p in ids:
        p.shoot_event = f"ev_{find(p.photo_id)}"
    for p in photos.values():
        if p.shoot_event is None:
            p.shoot_event = f"ev_{p.photo_id}"
    return photos

def independent_support(pairs, photos):
    """Считает независимые свидетельства (исправление E3): события, даты, источники, ракурсы."""
    events, dates, sources, poses = set(), set(), set(), set()
    for pr in pairs:
        for pid in (pr.photo_a, pr.photo_b):
            p = photos[pid]
            events.add(p.shoot_event); dates.add(p.date); sources.add(p.source); poses.add(p.pose_bin)
    return {"events": len(events), "dates": len(dates), "sources": len(sources), "poses": len(poses)}

def build_epochs(photos: dict, years_per_epoch: int = 2, manual_bounds: list | None = None):
    """
    Возвращает список эпох [{id, start, end, photo_ids}] по хронологии.
    manual_bounds: список годов-границ, напр. [2003, 2006, 2010].
    """
    dated = sorted([p for p in photos.values() if p.date_status == "ok"], key=lambda p: p.date)
    if not dated: return []
    years = [int(p.date[:4]) for p in dated]
    if manual_bounds:
        bounds = sorted(set([years[0]] + manual_bounds + [years[-1] + 1]))
    else:
        bounds = list(range(years[0], years[-1] + 1 + years_per_epoch, years_per_epoch))
    epochs = []
    for i in range(len(bounds) - 1):
        s, e = bounds[i], bounds[i + 1]
        ids = [p.photo_id for p in dated if s <= int(p.date[:4]) < e]
        if ids:
            epochs.append({"id": f"E{i+1:02d}", "start": s, "end": e - 1, "photo_ids": ids})
    return epochs

def coverage_matrix(epochs, photos):
    """Дополнение №12: эпоха × ракурс → число фото класса evidence / context."""
    mat = {}
    for ep in epochs:
        row = {b: [0, 0] for b in POSE_BINS}
        for pid in ep["photo_ids"]:
            p = photos[pid]
            row[p.pose_bin][0 if p.quality_status == "evidence" else 1] += 1
        mat[ep["id"]] = row
    return mat

def epoch_of(photo, epochs):
    y = int(photo.date[:4])
    for ep in epochs:
        if ep["start"] <= y <= ep["end"]: return ep["id"]
    return None

def epoch_stop_rule(epoch, pairs_in_epoch):
    """Дополнение №18: >30% пар не прошли ворота — выводы по эпохе недопустимы."""
    if not pairs_in_epoch: return "no_pairs"
    failed = sum(1 for p in pairs_in_epoch if p.gate_status != "pass")
    return "blocked" if failed / len(pairs_in_epoch) > 0.30 else "ok"

from dataclasses import dataclass, field

@dataclass
class Observation:
    obs_id: str
    zone: str
    channel: str               # geom | tex
    direction: str             # знак/направление изменения
    first_epoch: str
    support_pairs: list = field(default_factory=list)
    counter_pairs: list = field(default_factory=list)
    diary: list = field(default_factory=list)        # дополнение №2
    status: str = "insufficient"
    confidence: str = "none"
    alternatives: dict = field(default_factory=dict)  # дополнение №6
    shape: str = "unknown"      # step | trend | flat (дополнение №4)
    symmetric_with: str | None = None                 # дополнение №5
    survived_permutation: bool | None = None          # дополнение №7
    closing_request: str = ""                         # дополнение №13
    n_comparisons_in_epoch: int = 0                   # дополнение №25
    interpretation: str = "(заполняет редакция — система не интерпретирует)"  # №16

def bh_survivors(pvals: dict, q=BH_Q) -> set:
    """Бенджамини–Хохберг; pvals: key -> p. Возвращает ключи, пережившие поправку."""
    items = sorted([(p, k) for k, p in pvals.items() if p is not None])
    m = len(items); keep = set(); thresh = 0
    for i, (p, k) in enumerate(items, 1):
        if p <= q * i / m: thresh = i
    for i, (p, k) in enumerate(items, 1):
        if i <= thresh: keep.add(k)
    return keep

def _sign_dir(z: float, d: str) -> str:
    return d if d else ("увеличение" if z > 0 else "уменьшение")

def build_observations(pairs, photos, epochs, epoch_of) -> dict:
    """
    Из пар, прошедших ворота, строим нити наблюдений zone×channel×direction.
    Пара «рождает» сигнал, если |z| ≥ EFFECT_WEAK и p пережил BH внутри эпохи.
    """
    passed = [p for p in pairs if p.gate_status == "pass" and not p.is_control]
    # BH по эпохе, отдельно по каналам
    by_epoch = defaultdict(list)
    for pr in passed:
        ep = epoch_of(photos[pr.photo_b], epochs)  # эпоха более позднего фото
        by_epoch[ep].append(pr)
    survivors = {}
    n_comp = {}
    for ep, prs in by_epoch.items():
        pv = {}
        for pr in prs:
            for z, d in pr.zone_deltas.items():
                if getattr(d, "diagnostic_only", False): continue
                if d.geom_p is not None: pv[(pr.pair_id, z, "geom")] = d.geom_p
                if d.tex_p is not None:  pv[(pr.pair_id, z, "tex")] = d.tex_p
        survivors[ep] = bh_survivors(pv); n_comp[ep] = len(pv)

    threads: dict[tuple, Observation] = {}
    counter = 0
    for ep, prs in sorted(by_epoch.items(), key=lambda kv: kv[0] or ""):
        for pr in prs:
            for z, d in pr.zone_deltas.items():
                for ch, zval in (("geom", d.geom_z), ("tex", d.tex_z)):
                    if zval is None: continue
                    strong = abs(zval) >= EFFECT_WEAK and (pr.pair_id, z, ch) in survivors[ep]
                    direction = _sign_dir(zval, d.direction)
                    key = (z, ch, "+" if zval > 0 else "-")
                    anti = (z, ch, "-" if zval > 0 else "+")
                    if strong:
                        if key not in threads:
                            counter += 1
                            threads[key] = Observation(f"НАБЛ-{counter:03d}", z, ch, direction, ep)
                            threads[key].diary.append(
                                {"epoch": ep, "event": "родилось", "pair": pr.pair_id,
                                 "rule": f"|z|={abs(zval):.2f}≥{EFFECT_WEAK}, пережил BH(q={BH_Q})"})
                        threads[key].support_pairs.append(pr.pair_id)
                        threads[key].n_comparisons_in_epoch = n_comp[ep]
                        if anti in threads:
                            threads[anti].counter_pairs.append(pr.pair_id)
                            threads[anti].diary.append({"epoch": ep, "event": "противоречие",
                                                        "pair": pr.pair_id, "rule": "обратный знак ≥ порога"})
                    else:
                        # слабое или нулевое изменение в той же зоне = контр-свидетельство для существующей нити,
                        # если ожидали устойчивое отклонение
                        if key in threads and abs(zval) < EFFECT_WEAK * 0.5:
                            threads[key].counter_pairs.append(pr.pair_id)
                            threads[key].diary.append({"epoch": ep, "event": "не воспроизвелось",
                                                       "pair": pr.pair_id, "rule": f"|z|={abs(zval):.2f}<{EFFECT_WEAK*0.5}"})
    pairs_by_id = {p.pair_id: p for p in pairs}
    for obs in threads.values():
        _finalize(obs, pairs_by_id, photos, epochs, epoch_of, threads)
    return {o.obs_id: o for o in threads.values()}

def _finalize(obs, pairs_by_id, photos, epochs, epoch_of, threads):
    sup = [pairs_by_id[i] for i in obs.support_pairs]
    con = [pairs_by_id[i] for i in obs.counter_pairs]
    s = independent_support(sup, photos)
    c = independent_support(con, photos)

    # --- форма во времени (дополнение №4) ---
    pts = sorted((photos[p.photo_b].date, _z(p, obs)) for p in sup if _z(p, obs) is not None)
    obs.shape = _shape([z for _, z in pts])

    # --- симметрия (дополнение №5) ---
    mz = MIRROR.get(obs.zone)
    if mz:
        for key, other in threads.items():
            if other.zone == mz and other.channel == obs.channel and key[2] == ("+" if obs.direction.startswith("увел") or key[2]=="+" else "-"):
                obs.symmetric_with = other.obs_id

    # --- статус (дополнение №24, явные правила) ---
    if s["events"] == 0:
        obs.status = "insufficient"
    elif c["events"] > s["events"]:
        obs.status = "refuted"
    elif c["events"] * 2 >= s["events"] and c["events"] > 0:
        obs.status = "contested"
    elif s["dates"] >= 3 and s["poses"] >= 2 and s["sources"] >= 2:
        obs.status = "stable"
    elif s["events"] >= 2:
        obs.status = "reinforced"
    else:
        obs.status = "weak"
    if obs.shape == "trend" and obs.zone not in BONE_ZONES and obs.status in ("reinforced", "stable"):
        obs.status = "age_trend"
    if obs.symmetric_with and obs.shape == "trend":
        obs.status = "age_trend"

    # --- уверенность ---
    strong_eff = any(abs(_z(p, obs) or 0) >= EFFECT_STRONG for p in sup)
    if obs.status in ("insufficient", "refuted"):
        obs.confidence = "none"
    elif obs.status == "stable" and strong_eff and c["events"] == 0:
        obs.confidence = "high"
    elif obs.status in ("stable", "reinforced"):
        obs.confidence = "medium"
    else:
        obs.confidence = "low"
    if any(getattr(p, "evidence_grade", "context") == "context" for p in sup):
        obs.confidence = downgrade(obs.confidence)

    # --- альтернативы (дополнение №6) ---
    obs.alternatives = {
        "возраст": "возможна" if obs.shape == "trend" or obs.symmetric_with else "маловероятна (ступенька/асимметрия)",
        "вес": "возможна" if obs.zone not in BONE_ZONES or obs.zone in {"l_temple","r_temple","chin","l_mandible","r_mandible"} else "не объясняет костную зону",
        "мимика": "исключена (зоны рта вычеркнуты при открытом рте)" if obs.zone in BONE_ZONES else "возможна",
        "ракурс": f"ограничена воротами (Δ≤{max(p.delta_deg for p in sup):.1f}°)",
        "качество": "исключена" if all(getattr(p,'evidence_grade','')=='evidence' for p in sup) else "возможна",
        "освещение": "не проверялась (нужна ручная оценка)" if obs.channel == "tex" else "не влияет на геометрический канал",
        "ретушь": "текстура отфильтрована" if obs.channel == "tex" else "не влияет на геометрический канал",
    }

    # --- что закроет вопрос (дополнение №13) ---
    have_poses = set()
    have_sources = set()
    for p in sup:
        for pid in (p.photo_a, p.photo_b):
            have_poses.add(photos[pid].pose_bin); have_sources.add(photos[pid].source)
    missing_pose = next((b for b in POSE_BINS if b not in have_poses and b in _relevant_poses(obs.zone)), None)
    obs.closing_request = (
        f"кадр эпохи {obs.first_epoch} или следующей в ракурсе {missing_pose or 'любом другом'} "
        f"из источника, отличного от {', '.join(sorted(have_sources)) or '—'}")

def _z(pair, obs):
    d = pair.zone_deltas.get(obs.zone)
    if d is None: return None
    return d.geom_z if obs.channel == "geom" else d.tex_z

def _shape(zs):
    if len(zs) < 3: return "unknown"
    diffs = [b - a for a, b in zip(zs, zs[1:])]
    mono = sum(1 for d in diffs if d > 0), sum(1 for d in diffs if d < 0)
    if max(mono) >= 0.8 * len(diffs): return "trend"
    if max(abs(d) for d in diffs) >= 2 * (sum(abs(d) for d in diffs) / len(diffs)): return "step"
    return "flat"

def _relevant_poses(zone):
    if zone.startswith("l_"): return {"L_profile","L_deep","L_mid","L_light","frontal"}
    if zone.startswith("r_"): return {"R_profile","R_deep","R_mid","R_light","frontal"}
    return set(POSE_BINS)

        for z, d in p.zone_deltas.items():
            if d.geom_z is not None and abs(d.geom_z) >= 0.5:
                bad.append((p.pair_id, z, round(d.geom_z, 2)))
    return {"n_controls": sum(1 for p in pairs if p.is_control), "violations": bad,
            "passed": not bad}

def date_permutation(pairs, photos, observations, n_rounds=20, seed=7):
    """
    Дополнение №7. Перемешиваем даты между фото (в пределах пула фото с датами),
    пересобираем нити. Наблюдение «пережило», если при случайных датах
    его статус stable/reinforced встречается реже, чем в 20% раундов.
    """
    rnd = random.Random(seed)
    dated = [p for p in photos.values() if p.date_status == "ok"]
    hits = {oid: 0 for oid in observations}
    for _ in range(n_rounds):
        ph = copy.deepcopy(photos)
        dates = [p.date for p in dated]; rnd.shuffle(dates)
        for p, d in zip([ph[p.photo_id] for p in dated], dates): p.date = d
        eps = build_epochs(ph)
        obs2 = build_observations(copy.deepcopy(pairs), ph, eps, epoch_of)
        keyed = {(o.zone, o.channel, o.direction): o for o in obs2.values()}
        for oid, o in observations.items():
            o2 = keyed.get((o.zone, o.channel, o.direction))
            if o2 and o2.status in ("stable", "reinforced"): hits[oid] += 1
    for oid, o in observations.items():
        o.survived_permutation = (hits[oid] / n_rounds) < 0.2
        if o.status in ("stable", "reinforced") and not o.survived_permutation:
            o.status = "recheck"
            o.diary.append({"epoch": "-", "event": "понижено", "pair": "-",
                            "rule": f"воспроизводится при случайных датах в {hits[oid]}/{n_rounds} раундах"})
    return observations

# Замена детектора «возврата к прежнему лицу».
# Было: ratio = |delta_now| / |delta_prev| → взрыв при delta_prev→0.
ABS_MIN_DELTA = 1.0     # в z-единицах калибровки; ниже — «ничего не происходило»
MIN_DENOM = 0.5
REL_REVERSAL = 0.6

def reversal_flag(delta_prev: float, delta_now: float) -> tuple[bool, str]:
    """
    Возврат фиксируется только если: (1) было реальное отклонение ≥ ABS_MIN_DELTA,
    (2) знак сменился, (3) величина возврата ≥ REL_REVERSAL от прежнего отклонения,
    (4) знаменатель не меньше MIN_DENOM.
    """
    if abs(delta_prev) < ABS_MIN_DELTA:
        return False, "нет исходного отклонения"
    if delta_prev * delta_now >= 0:
        return False, "знак не сменился"
    denom = max(abs(delta_prev), MIN_DENOM)
    ratio = abs(delta_now) / denom
    return ratio >= REL_REVERSAL, f"ratio={ratio:.2f}"

Если stage2 не даёт geom_p/tex_p per zone, а даёт только z — адаптер вычисляет двусторонний p из нормального приближения (p = erfc(|z|/√2)), это честно при калибровке ≥20 точек.

Пункты из аудита, которые я не подтверждаю и не опровергаю без прогона:

    фактические значения порогов ретуши (RETOUCH_LIMIT) и размытия (MAX_BLUR_SCORE) — калибровать на 20–30 заведомо ретушированных/нерезких фото из архива;
    согласованность pose_bin из stage1 с политикой 9 ракурсов в atlas/ при yaw около границ бинов (риск «дрожания» бина между соседними кадрами одной сессии);
    достаточность 20 калиброванных точек как порога для профильных бинов, где видимых точек физически меньше;
    корректность p-значений stage2 после поправки: если stage2 уже применяет свою поправку, вторая BH по эпохе будет излишне консервативной — тогда адаптер должен брать «сырые» p.

8. Как это читает редакция

Итоговая папка report/ открывается в любом редакторе Markdown и читается сверху вниз: 00_baseline → 10_epoch_E01 → … → 90_route_sheet. Каждая страница эпохи — это готовый черновик раздела расследования: что было, что появилось, насколько верить, чем ещё объясняется, что проверить. Нити 40_obs_* — это карточки, которые можно положить рядом со статьёй как доказательную базу. Файл 91_cannot_say — обязательная врезка «ограничения метода», без которой публиковать нельзя.

Система не пишет текст статьи и не даёт вердиктов. Она даёт скелет, цифры с трассировкой до файлов и список того, что редакции нужно добыть, чтобы слабый сигнал стал устойчивым маркером — или рассыпался.
