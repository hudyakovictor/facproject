# app10 — калибровка на одном человеке

Цель: настроить и откалибровать на фото одного и того же человека (ракурсы/мимика) измерения 3D-геометрии, чтобы выделить ошибки реконструкции/нормализации/канонического поворота и исключать их при сравнении разных людей.

Принципы:
- Единая нормировка с продом: центр+RMS по 106 ландмаркам (`morphing.backend.aligner.normalize_ldm106`) как в валидации app9.
- Сравниваем `vertices_identity_only` (форма без мимики) в каноническом объектном пространстве 3DMM, без двойного поворота.
- Калибровка по бин-позам (по yaw). Замер дрейфа/шума внутри человека по метрикам формы.
- Фиксация протокола: что меряем, в каких единицах, пороги на одном человеке.

Структура:
- `scripts/` — извлечение, калибровка, диагностика
- `src/` — общие утилиты
- `data/meshes/`, `data/features/` — артефакты (в .gitignore)
- `reports/` — результаты калибровки
- `configs/` — конфиги
