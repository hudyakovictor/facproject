## Топ-5 к немедленному исправлению

**№1–2 связаны и образуют один краш-сценарий.** Как только `DEEPUTIN_STAGE2_ROOT`
укажет на реальный вывод Stage 2, таймлайн упадёт с `TypeError` при первом же
наведении курсора. Сейчас это не видно только потому, что research-режим не
включён. Исправление: тип `Photo` с `number | null` + проверка типов в
валидаторе + безопасное форматирование.

**№3 — нарушение нормативного документа.** Веса `1.0/0.8/0.7/0.6` в
`UnifiedTimeline` выглядят как данные атласа, но выдуманы в коде. Либо
вынести в атлас, либо убрать из подписей.

**№6 — доступность с медицинским риском.** Пульсирующие SVG-маркеры аномалий
не отключаются для пользователей с вестибулярными нарушениями.

**№4–5 — устойчивость.** Центральный элемент ТЗ (таймлайн) не защищён
boundary: одна ошибка рендера убирает весь экран.
