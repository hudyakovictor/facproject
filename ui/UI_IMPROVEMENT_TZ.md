# ТЗ доработок UI

**Стек**: React 19 + TS 5.9 + Vite 7. Сборка: 0 ошибок, 39 модулей, 317 KB.
**Данные**: 1809 синтетических фото (PRNG). Реальное API не подключено — fallback на демо.

## 1. Критические (без них UI бесполезен)

**1.1 API эндпоинты (11 шт.)**
`GET /api/v1/timeline` — список эпох с метаданными (дата, ракурс, качество).
`GET /photos/:id` — фото + метаданные (landmarks, mesh_id, yaw/pitch/roll).
`GET /photos/:id/mesh` — BFM mesh (35709 вершин, .npy или .json).
`GET /photos/:id/landmarks/{106,134}` — 2D/3D координаты ландмарок.
`GET /calibration/pair?yaw=&pitch=&roll=` — подбор ближайшей калибровочной пары.
`GET /compare/:a/:b` — попарное сравнение (12 метрик, diff).
`GET /compare/range?from=&to=` — сравнение диапазона эпох (среднее, тренд).
`GET /landmarks/drift?set=106&years=5` — drift ландмарок с LOESS.
`GET /clusters` — PCA-кластеризация фото.
`GET /events` — события (операции, инъекции, наблюдения).
`GET /stats` — агрегированная статистика (распределения, confidence).
Все запросы: loading spinner, error toast, retry-коллбэк, пустое состояние.

## 2. Функциональные

**2.1 Калиброванное сравнение**
При сравнении двух фото система подбирает из `calibration_dataset` пару с максимально близким ракурсом (yaw/pitch/roll). Вычисляется `calibrated_diff = raw_diff - calib_diff`. Если калибровочная пара отклоняется >15° по любой оси — индикатор красный, данные недостоверны. 5–15° — жёлтый (предупреждение). <5° — зелёный (достоверно). UI: цветной индикатор + подпись углов калибровочной пары.

**2.2 Drift ландмарок**
Четыре визуализации: (1) Drift Scatter — каждая точка = ландмарка, цвет = величина смещения; (2) LOESS тренд — сглаженная кривая drift по годам с доверительным интервалом; (3) Pose Grid 3×3 — матрица ракурсов, в каждой ячейке средний drift; (4) Heatmap Grid — тепловая карта drift по области лица. Фильтры: набор ландмарок (106/134), диапазон лет, минимальный confidence.

**2.3 Матрица сходства**
Тепловая карта: строки — эпохи, столбцы — метрики (silicone, specular, LBP, Frangi, wrinkle, subsurface, visualAge, calendarAge). Цвет ячейки — z-score относительно всей выборки. Клик по ячейке — детализация (фото, mesh, diff).

**2.4 PublicationsPanel**
CRUD публикаций: DOI, авторы, год, ссылка на фото/эпоху. Поиск/фильтр. Связь с эпохами — отображение маркеров на таймлайне.

**2.5 StatsDashboard**
Гистограммы распределения: качество фото, confidence ландмарок, diff по метрикам. Круговые диаграммы: доля аномалий по типу. Выбор периода. Экспорт в PNG.

## 3. Техдолг

**3.1 Рефакторинг App.tsx**
Сейчас 740 строк, 20+ useState, вся логика в одном компоненте. Выделить Zustand-стори: `usePlayheadStore` (текущая эпоха, диапазон), `useFilterStore` (активные фильтры), `usePanelStore` (открытые панели), `useCompareStore` (A/B выбор). HeaderBar — строгая типизация пропсов (сейчас `any`). Разделить App.tsx на хуки: `useTimelineData`, `usePhotoNavigation`, `useKeyboard`.

**3.2 Error Boundaries**
Обернуть: Timeline, LeftPanel, ComparisonPanel, Inspector3D, StatsDashboard, PublicationsPanel. Каждый Boundary — fallback UI с кнопкой «Повторить» и логом ошибки.

**3.3 Тесты**
vitest + @testing-library/react. Цели: утилиты (расчёт diff, z-score, LOESS), компоненты (рендер, состояния), api (мок-запросы, ошибки), стори (Zustand, мутации). Минимум 70% coverage.

**3.4 Производительность**
useMemo для SVG-путей силуэта и радиолокационной диаграммы. Виртуализация дорожек таймлайна (react-window). Мемоизация mesh-геометрии (useMemo + useLoader). Debounce фильтров (300ms).

## 4. UI/UX

**4.1 Силуэт лица**
SVG-контур лица, поворот по yaw (perspective transform). 21 анатомическая зона (лоб, глаза, нос, щёки, подбородок и т.д.). Цвет зоны — severity diff (зелёный/жёлтый/красный). Клик по зоне — детализация метрик.

**4.2 Радар кожи**
Radar-диаграмма (recharts или svg). 8 осей: silicone, specular, LBP, Frangi, wrinkle, subsurface, visualAge, calendarAge. Два слоя: текущее фото + среднее по эпохе. Интерактивный tooltip.

**4.3 Анимации**
Framer Motion: переходы между вкладками (fade + slide), пульсирующие маркеры аномалий на таймлайне, появление/исчезновение панелей (scale + opacity).

**4.4 Горячие клавиши**
Ctrl+Z / Ctrl+Shift+Z — undo/redo навигации. Ctrl+F — фокус поиска. 1–6 — переключение вкладок LeftPanel. Escape — закрыть модалку. Показывать список клавиш по `?`.
