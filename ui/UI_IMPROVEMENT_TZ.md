## 1. Критические (блокируют запуск на реальных данных)

### 1.1 Подключение реального API
- **Сейчас**: `api.ts` делает fetch к `/api/v1/timeline`, при ошибке падает на `PHOTOS` (синтетика)
- **Надо**: реализовать эндпоинты бэкенда:
  - `GET /api/v1/timeline` — основная лента
  - `GET /api/v1/photos/:id` — детали фото
  - `GET /api/v1/photos/:id/mesh` — 3D-сетка (BFM 35709 вершин)
  - `GET /api/v1/photos/:id/landmarks/{106,134}` — ландмарки
  - `GET /api/v1/calibration/pair` — калиброванная пара
  - `GET /api/v1/compare/:a/:b` — сравнение двух фото
  - `GET /api/v1/compare/range` — сравнение диапазонов
  - `GET /api/v1/landmarks/drift` — дрейф ландмарок
  - `GET /api/v1/clusters` — PCA/t-SNE кластеры
  - `GET /api/v1/events` — исторические события
  - `GET /api/v1/stats` — статистика коллекции
- **Приоритет**: высокий

### 1.2 Замена синтетических данных на реальные
- **Сейчас**: `data.ts` — 1809 фото, сгенерированных PRNG `mulberry32`
- **Надо**: удалить `data.ts` или оставить как fallback, все данные должны приходить с API
- **Приоритет**: высокий

### 1.3 3D-сетка (Inspector3D)
- **Сейчас**: `FullPhotoOverlay.tsx` — SVG-заглушка с синтетическими зонами и ландмарками
- **Надо**: интеграция `react-three-fiber` + `drei` для отображения BFM mesh (35709 вершин)
  - Загрузка mesh с `GET /api/v1/photos/:id/mesh`
  - Тепловая карта Point-to-Plane
  - Морфинг между двумя фото (слайдер 0–100%)
  - OrbitControls (вращение, зум, панорама)
- **Приоритет**: высокий
