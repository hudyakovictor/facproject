# Timeline V3 — анализ ошибок текущей версии

## Главный вывод

Текущая версия смешала сразу четыре несовместимые модели: календарный layout, sequence layout, LOD-прореживание и pair arcs. В результате фотографии наложились друг на друга, 200+ дуг превратились в оранжевую сетку, а навигационные элементы заняли top bar и низ экрана. V3 возвращает один понятный принцип: **все данные стоят на одной фиксированной последовательной сетке по кадрам**.

## 36 исправленных проблем

1. Удалены кнопки zoom `−/+` — масштаб снова управляется колесом.
2. Удалена кнопка «Вписать» — fit-all неизбежно накладывает 526 кадров в 1900 px.
3. Удалено переключение «Календарь/Последовательность» — два layout-режима создавали разные расстояния.
4. Удалены стрелки навигации из toolbar — drag и scroll достаточны.
5. Удалён нижний range/minimap, занимавший отдельный слой без аналитической пользы.
6. Wheel снова масштабирует без Ctrl/⌘.
7. Shift+wheel и горизонтальный wheel перемещают ленту.
8. Drag пустого места перемещает ленту.
9. Масштаб привязан к позиции курсора.
10. Установлена одна формула X: `index × (thumbnailWidth + 10 px)`.
11. Минимальная ширина thumbnail — 52 px.
12. Максимальная ширина — 112 px.
13. Между соседними thumbnails всегда 10 px.
14. Нахлёст невозможен конструктивно при любом масштабе.
15. LOD-пропуски удалены: ряд остаётся непрерывным.
16. Календарные gaps удалены из photo layout; время читается на ruler и hover.
17. На thumbnail нет даты, badge, score или цветной полосы.
18. На thumbnail остаётся только синяя selection-рамка.
19. Сотни pair arcs удалены: они нечитабельны при высокой плотности.
20. Pair data преобразованы в aligned graph tracks.
21. Главный graph показывает `meshMaxRobustZ` только adjacent-пар.
22. Второй graph показывает `meshVisibleFraction` как measurement support, а не evidence.
23. Candidate и limitation отмечаются точками на effect graph.
24. Цвет точки следует status/evidence, а не только z.
25. Под фото создан отдельный ряд ролей пар `A`, `B`, `A/B`.
26. Под ним создан отдельный ряд событий `◆`, `!`, `D`, `≈`.
27. Роли и события больше не конкурируют в одной иконке.
28. Хронологическая линейка находится строго под рядами иконок.
29. Годы привязаны к первому кадру года на общей X-сетке.
30. Дата кадра показывается по hover.
31. Hover также показывает pose, visibility и alignment.
32. Высота viewport распределяется динамически: graphs → photos → roles → events → ruler.
33. Graph получает всё свободное место, а не оставляет огромную пустую область.
34. Top bar сокращён до pose selector, контекста, safety-label и деталей кадра.
35. Footer содержит только три реально используемых жеста.
36. Исправлены inherited TypeScript null-errors для `meshMaxRobustZ` и отсутствующий helper `Row`.

## Вертикальный контракт V3

Сверху вниз:

1. **Calibrated effect graph** — основной pair signal.
2. **Measurement support graph** — применимость, визуально слабее.
3. **Photo row** — один непрерывный ряд без overlap.
4. **Pair role row** — A/B/A-B.
5. **Event row** — candidate/limitation/provenance/duplicate.
6. **Chronology ruler** — годы.

Все шесть слоёв используют одну X-координату кадра.

## Ограничения текущих данных

- `pair_metrics.json` содержит только 305 пар; график не является непрерывным measurement для всех 526 frontal frames.
- Full evidence state всё ещё частично выводится из status/FDR; frontend не должен расширять этот вывод.
- `meshMaxRobustZ` используется как величина effect track, но не как вероятность.
- Истинный calendar spacing сознательно не используется для thumbnails, потому что пользователь требует непрерывный ряд без overlap.
- Настоящие изображения лежат во внешнем `/storage/stage1`; архив UI содержит только данные.

## Приёмка V3

- Ни при каком wheel zoom thumbnails не пересекаются.
- Wheel увеличивает/уменьшает ленту без модификатора.
- Top bar не содержит zoom/fit/axis controls.
- Graph lines не образуют сетку из дуг.
- Роли пар и forensic-события находятся в двух разных рядах.
- Ruler находится ниже обоих рядов.
- В viewport нет неиспользованной нижней половины.
- TypeScript проходит без ошибок.
