# DEEPUTIN Forensic Suite UI

Автономный UI без npm-зависимостей и сети.

```bash
./RUN_PROJECT.sh ui
```

Открыть http://localhost:4173. Реализованы 9 pose bins, 14 timeline tracks, 8 режимов, evidence panels, calibrated comparison, 3D/BFM-ready inspector, drift, metrics, statistics и Fix Capsule v2. API-first endpoint: `/api/v1/timeline`; без API явно используется demo fallback.
