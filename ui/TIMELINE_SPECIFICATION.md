# DEEPUTIN Forensic Timeline — Спецификация реализации

## Статус: v2.0 — Базовый интерактивный таймлайн (80/20)

### ✅ Реализовано (Фаза 1-7)

#### Типы данных (`types.ts`)
- Полная структура Frame — все поля из `main_timeline.csv`
- 9 поз с цветовой палитрой (frontal → профили)
- Система метрик с настраиваемыми треками
- Система аномалий с типом/серьёзностью
- Статистика архива

#### Горизонтальный таймлайн (`Timeline.tsx`)
- **Строка миниатюр**: фото thumb.jpg из stage1 с fallback на цвет позы
- **Зум колёсиком**: динамический шаг (год → месяц → день) в зависимости от масштаба
- **Панорамирование**: drag перетаскиванием
- **Треки метрик**: SVG-графики с полилиниями и точками
- **Маркеры аномалий**: цветные блоки (critical=красный, high=оранжевый, medium=жёлтый)
- **Шкала времени**: динамическая разметка (годы/месяцы/дни)
- **Фильтр по позе**: выпадающий список

#### Детальный просмотр (`FrameDetail.tsx`)
- Полноэкранный оверлей с фото face_crop.jpg
- Данные: поза, покрытие, датировка, хронология, аномалии
- Миниатюры других фото в той же позе
- Статус-бар с метаданными

#### Главное приложение (`App.tsx`)
- Загрузка и парсинг `main_timeline.csv` (1910 строк)
- Статистический хедер: фото, аномалии, дубликаты, конфликты дат, ошибки геометрии
- Распределение по позам с цветными индикаторами
- Селектор отображаемых метрик (чекбоксы)
- Всплывающая панель статистики
- Русский язык интерфейса

### 🔍 50 анализов ТЗ (ключевые выводы для реализации)

1. **Центральный элемент — горизонтальный таймлайн**: реализован с миниатюрами
2. **Миниатюры фотографий**: загружаются из `/storage/stage1/{id}/thumb.jpg`
3. **Зум колёсиком**: масштабирование по оси времени
4. **Панорамирование через drag**: перетаскивание таймлайна
5. **Графики метрик**: 4 стандартных + настраиваемые треки
6. **Маркеры аномалий**: 5 типов (скачок, возврат, невозможный интервал, дубликат, конфликт дат)
7. **Фильтр по позе**: 9 поз + "все"
8. **Подсказки при наведении**: значение метрики, описание аномалии
9. **Детальный просмотр**: оверлей с полной информацией о фото
10. **Статус-бар**: подсказки по управлению
11. **Аномалии на миниатюрах**: красный индикатор на thumb
12. **Конфликты дат**: отображение conflictSources
13. **Дубликаты**: nearDuplicateOf с оценкой 30/120
14. **Ошибки геометрии/UV/сегментации**: цветовая индикация
15. **Цвета поз**: 9 уникальных цветов для pose bins
16. **Нет сайдбаров**: весь интерфейс — единый таймлайн
17. **Hover-поведение**: плавающие панели с данными
18. **Статистика агрегированная**: общее кол-во, аномалии, дубликаты
19. **Распределение по годам**: шкала с годами
20. **График видимости**: combinedVisibleFraction
21. **График покрытия кожи**: skinMaskCoverage
22. **График UV покрытия**: uvObservedCoverage
23. **График аномалий**: anomalyScore
24. **Аномалия "gap"**: разрыв >3 лет между фото
25. **Аномалия "скачок видимости"**: >15% change в <90 дней
26. **Аномалия "скачок позы"**: >45° yaw change в <30 дней
27. **Статус геометрии**: valid/invalid/unknown
28. **Статус сегментации**: valid/invalid/unknown
29. **Статус UV**: valid/invalid/unknown
30. **Происхождение даты**: filename_only / exif / conflict
31. **Индекс хронологии**: global + in-pose
32. **Fallback thumbnails**: цвет по позе если нет фото
33. **Тёмная тема**: forensic dark palette (#0a0e14 base)
34. **Динамическая шкала**: переключение год/месяц/день
35. **Выбор активных метрик**: чекбоксы в выпадающем меню
36. **Статус-бар с хоткеями**: подсказки по управлению
37. **Выбранное фото**: подсветка синим кольцом
38. **Аномалия "статус ошибка"**: geometryStatus !== 'valid'
39. **Адаптивная ширина фото**: 8-70px в зависимости от зума
40. **FRONTAL анфас**: отдельный цвет (#38bdf8)
41. **Левый/правый профиль**: серый и красный (#94a3b8/#f87171)
42. **Ленивая загрузка**: loading="lazy" для миниатюр
43. **3/4 метрические углы**: 6 разных цветов для 3/4 ракурсов
44. **Качество реконструкции**: inferred from alignment_quality
45. **Кэширование через HTTP**: Cache-Control на фото
46. **Интеграция с stage1**: загрузка напрямую с /Volumes/SDCARD
47. **Только ценные данные**: отфильтрованы шумные поля
48. **Compact layout**: вся информация на одном экране
49. **Минимум скролла**: вертикального нет, только горизонтальный таймлайн
50. **Производительность**: виртуализация visibleRange
