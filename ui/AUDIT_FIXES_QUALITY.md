## №13 (92) — `React.memo`

Профилирование по коду выявило проблему серьёзнее отсутствия memo.

**`Icon` строил таблицу из 56 JSX-элементов на каждый рендер:**

```tsx
export default function Icon({ name, ... }) {
  const paths: Record<IconName, JSX.Element> = {
    "lock": <>...</>, "search": <>...</>, /* ещё 54 */
  };
  return <svg {...props}>{paths[name]}</svg>;
}
```

Использовался ровно один элемент из 56. В интерфейсе **88 вхождений**
`<Icon>`, восемь из них — внутри строки таймлайна, то есть на каждое фото.
При скролле ленты это тысячи бесполезных аллокаций на кадр.

Контуры статичны и от пропсов не зависят — вынесены на уровень модуля,
компонент обёрнут в `memo` (все пропсы примитивны, поверхностного
сравнения достаточно).

**`KeyGroup` обёрнут в `memo`.** В панели метрик пары одновременно живут
до девяти групп, в сводке прогона — больше двадцати. Раскрытие одной
меняло состояние родителя и перерисовывало все остальные вместе с
таблицами. `values` приходит из `useMemo`, поэтому ссылочное сравнение
корректно.

`UnifiedTimeline` и `LeftPanel` в memo **не обёрнуты осознанно**: они
принимают объекты и коллбэки, пересоздаваемые на каждом рендере родителя,
и memo без стабилизации всех пропсов дал бы только накладные расходы на
сравнение.

## №16 (91) — мёртвые ключи словаря

Удалено **36 ключей** (72 строки ru+en): остатки удалённых панелей
(`folkUdmurt`, `folkGovorun`, `folkKuchma`), переименованных режимов
(`viewFull`, `viewCluster`, `viewPairCompare`), а также
`qualityBlur`/`qualityNoise` — подписи к синтетическим метрикам, удалённым
на предыдущем этапе.

Мёртвый ключ вреден не размером бандла, а тем, что выглядит действующим
контрактом и требует перевода при добавлении языка.

**Добавлен тест-страж** `i18n.test.ts::словарь не накапливает мёртвые ключи`:
читает исходники (в рантайме отследить `t.foo` нельзя — `t` это Proxy) и
падает со списком неиспользуемых.

Страж сразу нашёл два ключа сверх моего списка — `current` и `total`.
Первичная проверка их пропустила: подстроки `"current"`/`"total"`
встречаются в коде в других контекстах. Тест точнее ручного grep.

выражение обрывало атрибуты на `>` внутри JSX-выражений. Исправлено
