# DEEPUTIN Timeline — Редизайн 2.0 (видение с полной свободой)

**Дата:** 2026-08-18 · **Автор:** UI/UX-эксперт (99 уровень)
**Мандат:** полная свобода переделки таймлайна. Цель — сделать в 2 раза лучше и на 200% удобнее для журналиста-расследователя, работающего с архивом 1999–2026, 9 ракурсов, 1909 кадров, 305 пар.

---

## 0. Главный вывод

Текущий таймлайн — **отличный рентгеновский снимок одного ракурса** и плохая **навигационная система архива**. Он показывает детали (z-точки пар), но не показывает:
- **карту 28 лет целиком** (макро-уровень отсутствует);
- **все 9 ракурсов одновременно** (корроборация = ручное переключение селектора);
- **время честно** (ось X = индекс кадра, а не календарь — редкие 90-е сжаты, плотные 2008–2012 растянуты);
- **поток работы** (проверка 52 кандидатов = 52 открытия/закрытия модала).

Редизайн строится на четырёх ходах: **(1) три уровня масштаба, (2) многодорожечная сетка ракурсов, (3) честная шкала времени, (4) инспектор-панель вместо модалов + режим «обход кандидатов».** Всё остальное — производное.

## 1. Двенадцать принципов (что стоит за каждым решением)

1. **Один экран = один вопрос.** Сейчас экран одновременно отвечает на 6 вопросов (геометрия, поддержка, применимость, качество, события, роли) — ни на один хорошо. Новый дефолт: фото + кривая стабильности + события. Остальное — по требованию.
2. **Сначала карта, потом детали.** Любой инструмент анализа времени обязан иметь zoom-out до «всего архива на одном экране».
3. **Время — честная ось.** Календарь, а не номер кадра. Плотные периоды кластеризуются, редкие — показывают реальные пробелы (это само по себе факт для расследования: «в 1999–2001 всего 21 кадр»).
4. **Сигнал и контекст — разные каналы.** Сигнал (кандидат/аномалия) — только форма+цвет статуса. Контекст (ракурс, качество, дата) — подписи и фон. Сейчас 9 цветов поз конкурируют с 4 цветами статусов — визуальный шум.
5. **Кросс-ракурсная корроборация — взглядом, не кликами.** Кандидат должен быть виден одновременно на фронте и в профиле.
6. **Никаких модалов в потоке.** Боковая панель сохраняет контекст. Модал — только для 3D-сцены.
7. **Клавиатура — основной инструмент.** Всё, что делается мышью, делается клавишами; прогресс обхода виден.
8. **Периоды — объекты.** «2008–2013» — это не диапазон прокрутки, а кликабельный объект с пресетами (эпохи ТЗ: 1999–2007, 2008–2013, 2014–2019, 2020–2026).
9. **Честность данных сохраняется.** Кандидат ≠ вердикт; robustZ зон некалиброван; raw rmse вместо z. Редизайн не меняет методологию — меняет подачу.
10. **Аннотации на оси времени.** Журналист оставляет след: «проверить публикации СБУ», «гипотеза: смена 2012». Ось без заметок — это блокнот без ручки.
11. **60 fps или ничего.** Canvas для кривых и точек >300, виртуализация фото-ряда, IntersectionObserver для миниатюр.
12. **Обучение за 60 секунд.** Первый запуск — 3 интерактивных шага + легенда по «?».

## 3. Двенадцать трансформаций «было → стало»

### 3.1. Уровни масштаба (главный ход)
**Было:** один бесконечный зум 60–128px на слот; zoom-out не даёт ничего, кроме мельчайших миниатюр; обзора нет.
**Стало:** три явных уровня, как в картах:
- **L0 «Стратегическая карта»** (весь архив): 9 рядов × 28 лет, тепловые ячейки max z, ◆-кандидаты, n кадров. Ответ за 1 взгляд: «где вообще происходило что-то, а где данных нет». Это MatrixView, ставший уровнем таймлайна, а не спрятанным разделом.
- **L1 «Период»** (год–3 года): таймлайн с кластеризацией плотных месяцев, z-кривая, фото-ряд.
- **L2 «Кадр»** (зум до 112px): текущий детальный режим с same-day стеками.
Wheel проваливается L0→L1→L2; стрелки навигации по уровням; LOD сбрасывает ненужные слои автоматически.

### 3.2. Многодорожечная сетка ракурсов
**Было:** селектор позы в toolbar; один ракурс за раз; чтобы сравнить фронт и профиль — 2 клика + потеря контекста.
**Стало:** активный ракурс — главная дорожка (высота ~70%), остальные 8 — контекстные полосы по 14px под ней с точками-кадрами и ◆-кандидатами. **Вертикальное выравнивание по времени** — кандидат 2012 года на фронте и в профиле видны друг над другом. Клик по контекстной полосе делает её активной. Кнопка «только активный» — для работы в старом стиле.

### 3.3. Честная ось времени
**Было:** X = индекс кадра; 1999–2005 занимает столько же, сколько 2008–2010.
**Стало:** X = календарное время с **минимальным зазором** (2px) между соседями: плотные периоды уплотняются до читаемого минимума, редкие — честно растягиваются. Пробел в 2 года без фото виден как пробел — для «археологии архива» это доказательный факт. Переключатель «время/порядок кадров» остаётся для сравнения соседей.

### 3.4. Кривая стабильности вместо россыпи точек
**Было:** 305 разрозненных точек пар в 4 графических зонах; «а что в целом происходит?» — не ответить.
**Стало:** одна **кривая «стабильность идентичности»** = скользящее окно (3–5 смежных пар ракурса), медиана z + доверительный коридор калибровки (затенённая полоса «нормы»). Точки пар — под кривой маркерами (◆/▲/·). Аномалии — цветные **интервальные полосы** под кривой: persistence = широкая красная, одиночный скачок = узкая жёлтая, возврат = пунктирная. Кривая делает главный вопрос ТЗ («устойчивый сдвиг или скачок?») ответом на один взгляд.

### 3.5. Слои-режимы вместо 14 чекбоксов
**Было:** меню «Данные» с 11 чекбоксами, все включены по умолчанию — графический шум.
**Стало:** **радио-режим слоя** (один активен, переключение горячей клавишей 1/2/3):
- **Геометрия** (дефолт): z-кривая + пары + persistence.
- **Текстура/кожа**: аутентичность, качество кожи, резкость (diagnostic-бейдж).
- **Контекст**: видимость, мимика, alignment, резкость — для QC.
Плюс «сравнить слои» (два слоя полупрозрачно, режим наложения) — для поиска корреляций «текстура vs геометрия» (важно для гипотезы силикона: смена геометрии + скачок текстуры в одну дату = сильный сигнал).

### 3.6. Инспектор-панель вместо модалов
**Было:** клик по паре → полноэкранный оверлей; контекст таймлайна теряется; 52 кандидата = 52 «открыть/закрыть».
**Стало:** боковая панель 380px (справа), синхронная с выделением: A/B фото, z, 11 гейтов (свёрнуты в «ступени»: видно 3 верхних, остальные по клику), кнопки [в очередь] [заметка] [3D] [←] [→]. Таймлайн остаётся живым: стрелки двигают кандидата, панель перерисовывается. Esc закрывает панель, но выделение на таймлайне остаётся.

### 3.7. Режим «Обход кандидатов» (поток)
**Было:** очередь в отдельном разделе, вне контекста времени.
**Стало:** режим на самом таймлайне: playhead бежит по 52 FDR-кандидатам (все ракурсы), каждый — с подсветкой пары и панелью; клавиши **1/2/3** — решение прямо в потоке (как в Casework), прогресс «7/52» в тулбаре; пробел — пауза; Esc — выход из режима с сохранением позиции. Раздел «Проверка кандидатов» остаётся как табличный вид того же списка.

### 3.8. Периоды как объекты + возрасты и события
**Было:** линейка только с годами; «фильтр по периодам» отсутствовал.
**Стало:** на линейке — **вертикальные линии возрастов** (В. Путину 40/50/60/70) и **публичных событий** (2000 инаугурация, 2008–2012 премьерство, 2012 инаугурация, 2020 поправки, 2022 — включается/выключается, т.к. границы спорные). Клик по линии события — фильтр-подсветка периода. Пресеты эпох ТЗ в левой панели: 1999–2007 / 2008–2013 / 2014–2019 / 2020–2026 + произвольный диапазон слайдером прямо на линейке (brush-выбор).

### 3.9. Аннотации на оси
**Было:** SessionJournal (журнал действий) без привязки ко времени.
**Стало:** маркеры-флажки на датах: «+ Заметка» (текст, цвет-категория: гипотеза/проверить/вывод). Хранятся в localStorage + экспортятся в отчёт. Хоткей N — новая заметка на выделенной дате. Журнал сессии остаётся, но заметки — первый класс объектов на оси.

### 3.10. Палитра: сигнал отдельно от контекста
**Было:** 9 цветов поз + 4 цвета статусов + 5 цветов z-точек + 14 цветов треков.
**Стало:** три сигнальных цвета (синий = норма/контекст, жёлтый = внимание/кандидат, красный = persistence/критично) + нейтральные для всего остального. Позы на контекстных полосах — буквенные глифы (Л/П/Ф и т.п.) или одна серая гамма; цвет позы остаётся только у активной дорожки и в легенде. Шрифты: минимум 11px, моно для чисел, sans для текста; hit-зоны ≥20px.

### 3.11. Производительность
**Было:** SVG всех 305 пар и 1909 кадров, hover-пересчёты на каждый mousemove.
**Стало:** кривые и точки — **canvas** при >300 элементов; фото-ряд — DOM с виртуализацией и `content-visibility`; ховер — throttled (16ms) и только по ближайшей точке через kd-дерево/биннинг; зум/панорама — rAF. Цель: 60fps на drag/zoom при полном архиве, проверка на 1920×1080 и 1366×768.

### 3.12. Экспорт и обучение
**Было:** экспорт отчёта в разделе, снапшота вида нет; обучение отсутствует.
**Стало:** кнопка **«Снимок вида»** — PNG текущего экрана (L0/L1/L2) с водяным знаком «КАНДИДАТЫ — НЕ ВЕРДИКТ» и датой — для рабочего блокнота. Онбординг: 3 шага при первом запуске (карта → период → кадр) + легенда по «?».

## 5. Что НЕ трогать (сильные стороны)

- **Единая X-сетка** всех слоёв — фундамент, остаётся.
- **Честность статусов** («кандидат ≠ вердикт», «не фабриковать z») — принцип, остаётся.
- **Клавиатурный контур** ←/→, [/], C, Esc — расширяется, не заменяется.
- **Same-day стеки**, не ломающие сетку — переходят в L2 как есть.
- **Persistence-заливки** — становятся частью кривой (3.4), идея сохраняется.
- **Валидация данных, контракт, selftest** — не трогаются вообще.

## 7. Метрики «200%» (как проверить, что стало в 2 раза лучше)

1. Время до ответа «что происходит в архиве»: >3 мин → **<30 сек**.
2. Кликов до кросс-ракурсной проверки кандидата: 5 → **0**.
3. Время полного обхода 52 кандидатов: ~90 мин → **≤45 мин**.
4. Количество одновременно видимых ракурсов: 1 → **9**.
5. Число видимых «сообщений» на дефолтном экране: 6 → **1 (кривая) + контекст**.
6. Действий до экспорта снапшота: 0 (нет функции) → **1 клик**.
7. Ошибок интерпретации новичком (легенда): 11 символов → **3 сигнальных цвета + текст**.

### Сознательные упрощения (отклонения от видения)
1. **Снимок PNG** → HTML-экспорт: без внешних зависимостей честный PNG-рендер не сделать; HTML-снимок содержит те же данные + вотермарку.
2. **Зум по уровням L0/L1/L2** → явное переключение «Карта ↔ лента» вместо wheel-проваливания между режимами (wheel остаётся непрерывным зумом внутри ленты; карта — отдельный режим с той же сеткой данных).
3. **Аннотации** — без редактирования текста (создание через 📌, удаление кликом); экспорт в снимке и localStorage.
4. **Модал FrameDetail** оставлен для одиночного кадра; панель-инспектор — для пар (основной поток).

### Метрики после внедрения (проверяемо)
- Кросс-ракурсная проверка кандидата: 5 кликов → **0** (контекст-полосы + ◆).
- Обзор 28 лет: прокрутка → **1 клик «Карта»**.
- Обход 52 кандидатов: 52 модала → **режим обхода с 1/2/3**.
- Пробелы данных (1999–2001): невидимы → **видны на календарной оси**.
