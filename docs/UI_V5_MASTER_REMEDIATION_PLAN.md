## 0. Главный принцип планирования

Аудит показал, что дефекты **не независимы**. 253 захардкоженных цвета, мёртвая светлая тема, провалы a11y и 15 цветов вне токенов — это не 4 задачи, а **одно следствие** того, что дизайн-система не подключена (D10). Аналогично: неработающий TopBar (BUG-1), отсутствие permalink (G-06) и рассинхрон pose bins (BUG-2) — следствия отсутствия единого стора состояния.

Поэтому план построен не по списку симптомов, а **по первопричинам**, и упорядочен так, чтобы каждая следующая фаза опиралась на готовый фундамент, а не переписывала его.

Второй принцип: **сначала честность, потом функциональность.** Дефекты D1–D9 означают, что интерфейс судебной экспертизы прямо сейчас выводит недостоверные утверждения (Stage-1 подписан как Stage-2, `null` показан как `0.00`). Пока это не исправлено, любая новая функция тиражирует ложь на ещё один экран. Фаза 0 стоит ~5 дней и снимает весь этот класс.

Третий принцип: **никакой новой страницы, пока не закрыт фундамент.** Каждая страница, написанная до Фазы 3, добавит ещё один файл с сырыми `<button>` и хардкод-хексами.

## 2. Definition of Done — применяется к каждой задаче

Задача считается закрытой, только если выполнены **все** пункты:

1. `npx tsc --noEmit` — 0 ошибок; `npx eslint .` — 0 ошибок, 0 предупреждений.
2. Unit-тест на **сценарии отказа**, а не только на happy path: пусто / HTTP 500 / `null`-метрика / Stage-1-режим. Именно отсутствие таких тестов позволило D3, D5, D101 дожить до релиза при 6/6 зелёных.
3. Ноль сырых `<button>`, `<select>`, `<input>` — только `shared/ui/primitives`.
4. Ноль литералов `bg-[#…]` / `text-[#…]` / `border-[#…]` — только токены.
5. Ни одного числа в JSX, не выведенного из данных (запрет литералов вида `13`, `6/24`, `4`).
6. Ни одного `?? 0` / `== null ? 0` на метрике. Отсутствие данных → `н/д` через `MetricValue`.
7. Все пользовательские строки — через i18n-ключ (после Ф11 — обязательно; до неё — через константу модуля).
8. Экран отрабатывает три состояния явно и по-разному: **loading / empty / error** (D5).
9. Маркер `ОТОБРАЖЕНИЕ ДАННЫХ · НЕ ВЕРДИКТ` виден (обеспечивается status bar, но проверяется).
10. Все ошибки ушли в `consoleLogger` (D16).
11. Состояние экрана закодировано в URL и воспроизводится по ссылке (G-06).
12. Обновлён `docs/codegpt/FILE_REGISTRY.md` и `DECISION_LOG.md` согласно `AGENTS.md`.
