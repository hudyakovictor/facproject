# Требования к разработчику: внедрение улучшений DEEPUTIN Pipeline

## Общие требования к коду

1. **Язык**: Python 3.11+, стиль — строгая типизация (PEP 484), `from __future__ import annotations`
2. **Тесты**: Каждый новый модуль — минимум 3 теста (pytest), все существующие 87 тестов должны проходить
3. **Документация**: Каждая функция — docstring с описанием, статусом (`# status: new/in_progress/complete`), предупреждениями
4. **Обработка ошибок**: Все функции — fail-closed (raise на некорректные данные), никаких silent pass
5. **Производительность**: CPU-only (Apple Silicon M1), без CUDA, без тяжелых зависимостей >100MB
6. **Совместимость**: Не ломать существующий API Stage 1 → Stage 2 → Stage 3

### 1. Дифференциальное вычитание углового шума калибровки (Angle Noise Subtraction)

**Файл**: `app6/stage2/calibration.py` (новый модуль или расширение)

**Что сделать:**
- Для каждой анализируемой пары фото (A, B) вычислить разницу углов: `Δyaw = |yaw_A - yaw_B|`, `Δpitch`, `Δroll`

- Если подходящая калибровочная пара не найдена (допуск ±2° по yaw, ±1° по pitch/roll) — выставить флаг `angle_noise_uncompensated`

**Сигнатура**:
```python
def subtract_angle_noise(
    pair_metrics: dict,
    calibration_index: pd.DataFrame,
    tolerance: dict[str, float] = None
) -> dict:
    """Возвращает pair_metrics с вычтенным угловым шумом и флагом компенсации."""
```

**Тесты**:
- Компенсация снижает RMSE для известной калибровочной пары
- Флаг `angle_noise_uncompensated` при отсутствии подходящей пары
- Граничные случаи: Δyaw = 0, Δpitch = 0
