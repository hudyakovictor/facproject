## 1. Что сделано

### Попап пары — ландшафтный (шире, чем выше)
- **Пропорции монитора:** `width: min(1480px, 95vw)` × `height: min(78vh, 900px)` — на любом экране ширина больше высоты (16:9–16:10).
- **Полностью новая вёрстка** (классы `pp-*`):
  - **Верхний ярус — фото A | Δ | B в ряд**: крупные face_crop с метаданными каждого кадра (yaw/pitch/roll, видимость, align, резкость, шум, улыбка, челюсть) в сетке 2×4; между фото — вертикальная Δ-панель (Δ max z с цветовой кодировкой, Δ alignment, мимика A/B, бейдж FDR10, метка диагностической роли).
  - **Средний ярус — 8 карточек ключевых метрик** (4×2): max robust z, FDR q, видимость+вершины, Δ alignment, резкость A/B, кожа z A/B, калибровка+elevated, выравнивание+зоны.
  - **Нижний ярус — зоны + гейты** (2 колонки): слева heat-карта 3×3 с интенсивностью raw rmse и топ-5 зон, справа — все 11 гейтов в 2 колонках (компактные аккордеоны, скролл).
  - Заголовок: статус-лейбл пары + evidence level; футер: полный дисклеймер «кандидат ≠ вердикт».

### Страница сравнения A/B — полный редизайн
- **Новая структура:** шапка (режимы + зум + клавиатурные подсказки) → рейлы A/B по бокам (10 метрик каждого кадра) → сцена → футер (8 карточек дельт + легенда тепловой шкалы 0–100%).
- **Три режима сцены:**
  - «Рядом» (s) — классическое сравнение с общей панорамой/зумом;
  - «Наложение» (o) — A поверх B **с ползунком прозрачности**;
  - «Разделитель» (d) — одно полотно, перетаскиваемая граница A|B (слайдер с клавиатурной доступностью).
- **Зоны:** оверлей 3×3 с подписями значений rmse и tooltip'ами, легенда-градиент в футере.
- **Клавиатура:** `+`/`−` зум, `0` сброс, `s`/`o`/`d` режимы, `z` зоны, `Esc` закрыть.

## 4. Как проверить (QA-чеклист)

1. Открыть пару (клик по точке на таймлайне → Enter) — попап шире, чем выше, на 1920×1080 и 1366×768.
2. Кнопки `Атлас / Очередь / Сравнить / 📌 / Закрыть` работают; `←`/`→` листают пары без закрытия.
3. «Сравнить» → страница A/B: `s`/`o`/`d` переключают режимы; в «Наложении» ползунок меняет прозрачность; в «Разделителе» граница тянется; `+`/`−` зум; `0` сброс; `z` зоны; `Esc` закрывает.
4. В рейлах A/B видны 10 метрик каждого кадра; в футере — 8 карточек дельт и легенда тепловой шкалы.
5. `npm run verify` — зелёный (tsc + oxlint + selftest + 7 тестов); `vite build` — успешен.
