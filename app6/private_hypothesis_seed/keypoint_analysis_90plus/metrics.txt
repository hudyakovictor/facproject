Источник определений: keypoint_metric_definitions_90plus.csv, analyze_keypoints_90plus.py,
cross_validate_keypoints.py, keypoint_features_90plus.csv, keypoint_aba_top25.csv,

Все 17 базовых метрик вычисляются поверх 106 выровненных ландамарков, предварительно
центрированных и изотропно отмасштабированных по множеству точек с видимостью >= 90%.
Индексы ландамарков — 0-_based (позиция == landmark_id после сортировки по landmark_id).

=== ПРОИЗВОДНЫЕ МЕТРИКИ (по 17 базовым, робастная нормировка) ===

Нормировка: med = медиана по 144 кадрам; mad = 1.4826 * медиана|X-med| (при mad<1e-8 -> std+1e-8);
Z = (X - med)/mad  — поглот-робаст z-оценка каждой базовой метрики.

18) geometry_anomaly_score — Средняя |z| по 5 самым выбивающимся метрикам кадра:
   mean(sort(|Z|)[-5:]). Широкие изменения формы -> высокий скор; одиночный пик сдерживается.

19) features_over_2_5mad — Число метрик кадра с |z| >= 2.5.

20) top_changed_features — Топ-5 имён метрик по убыванию |z| для кадра.

=== МЕТРИКИ A-B-A (возврат к базовой линии; соседние по времени кадры одного человека) ===

Для окна из трёх последовательных по дате кадров A(i-1), B(i), C(i+1) в робастном z-пространстве:
21) d_ab = ||Z[i-1]-Z[i]|| / sqrt(17)
22) d_bc = ||Z[i]-Z[i+1]|| / sqrt(17)
23) d_ac = ||Z[i-1]-Z[i+1]|| / sqrt(17)
24) aba_score_geometry = (d_ab + d_bc)/2 - d_ac   (высокий = B выбивается, A и C похожи)
25) return_features_count / return_features — метрики, где B отличается от обеих A/C (>1 MAD),
   а A~C (<=1 MAD): per = min(|Z[i]-Z[i-1]|,|Z[i]-Z[i+1]|); маска = (per>=1) & (|Z[i-1]-Z[i+1]|<=1).

=== МЕТРИКИ КРОСС-ПРОВЕРКИ 106 vs 134 (cross_validate_keypoints.py) ===

Координатный аномалий-скор по точкам (без семантических метрик): нормировка по видимым >=90%,
z = |X-med|/mad по всем координатам; скор = mean(sort(z)[-18:]).
26) score106_coords — координатный аномалий-скор по 106 ландамаркам.
27) score134_coords — координатный аномалий-скор по 134 ландамаркам.
28) rank106 / rank134 — ранги кадров по убыванию скора; both_top25 — в топ-25 обоих наборов.
   (rank correlation 106/134 = 0.980, top25 overlap = 22/25.)

=== ДИАГНОСТИКА КЛАСТЕРОВ (cluster_diagnostics) ===

29) k — число кластеров (2..6); silhouette — средняя силуэтная близость (0..1);
   sizes — популяции кластеров. Это кластеризация 144 кадров ОДНОГО человека по форме (позы/возраст),
   НЕ разные личности.

=== ВАЖНО ПРО «ТРОИХ» ===
Во всех файлах папки нет данных о трёх личностях (put/vas/udmurt). «a-b-c» — это три соседних
по дате кадра (тест возврата), «две колонки» — 106 vs 134 ландамарки, «k=3» — трёхкластерная
разбивка формы одного человека. Три лица как данные существуют только в /Volumes/SDCARD/test_photos.

=== СЕМАНТИЧЕСКАЯ КАРТА ИНДЕКСОВ 106 (0-based) ===
  Контур лица/челюсть : 0..32   (16 = центр подбородка; 10/22 = углы челюсти (gonion);
                                   0/32 = височно-скуловые extremes; 8/24 = средн. щека)
  Брови                 : лев. 33..41, прав. 42..50   (34..40 / 42..50 — тело брови)
  Нос                   : спинка 51(radix)..54(кончик); бока 55..57 (лев) / 65..63 (прав);
                          основание/крылья 58..62 (60 = центр основания)
  Глаз левый (разрез)   : углы 66(внешний)/70(внутренний); верхн. век 66..70 (apex 68);
                          нижн. век 70..66 (apex 72); центр ~74
  Глаз правый (разрез)  : углы 75(внутр.)/79(внешний); верхн. век 75..79 (apex 77);
                          нижн. век 79..75 (apex 81); центр ~77
  Доп. якоря орбит      : 104 (лев), 105 (прав)
  Рот                   : углы 84/90; верхн. губа 85..89 (apex 87); нижн. губа 91..95 (apex 93);
                          обводка 96..103

=== МЕТРИКИ ГЛАЗНОЙ ЩЕЛИ (разрез/форма глаза) ===
  eye_open_L   = ||q[68]-q[72]||      вертикальное открытие левого глаза
  eye_open_R   = ||q[77]-q[81]||      вертикальное открытие правого глаза
  eye_wid_L    = ||q[66]-q[70]||      ширина разреза левого глаза
  eye_wid_R    = ||q[75]-q[79]||      ширина разреза правого глаза
  eye_aspect_L = eye_wid_L/eye_open_L      aspect-ratio (шир/выс) левого
  eye_aspect_R = eye_wid_R/eye_open_R      aspect-ratio правого
  eye_open_asym= |eye_open_L-eye_open_R|    асимметрия открытия
  eye_wid_asym = |eye_wid_L-eye_wid_R|      асимметрия ширины
  eye_separation = ||eye_ctr_L-eye_ctr_R||  межзрачковое (центры век)
  eye_rel_open   = (open_L+open_R)/(wid_L+wid_R)   «раскрытость» глаз

=== МЕТРИКИ ЧЕЛЮСТИ / ПОДБОРОДКА ===
  lower_face_h   = |q[60].y - q[16].y|        высота нижней трети (основание носа->подбородок)
  bigonial       = ||q[10]-q[22]||            ширина нижней челюсти (углы)
  mandible_L     = ||q[16]-q[10]||            длина ветви слева (подбородок->угол)
  mandible_R     = ||q[16]-q[22]||            длина ветви справа
  mandible_asym  = |mandible_L-mandible_R|    асимметрия челюсти
  chin_proj      = q[16].z - mean(q[10].z,q[22].z)   сагиттальная выступающая/ретроgnatia
  jaw_to_mouth   = bigonial / ||q[84]-q[90]||        челюсть относительно ширины рта
  lower_upper_ratio = lower_face_h / |q[35].y - q[60].y|   нижняя треть к средней

=== МЕТРИКИ ПРОПОРЦИЙ ЛИЦА ===
  face_height    = |brow_top.y - q[16].y|         brow_top = max(q[35].y, q[44].y)
  bizygomatic    = ||q[0]-q[32]||                 ширина лица по скулам/вискам
  face_wh        = bizygomatic / face_height       ширина/высота лица
  upper_mid_ratio= |eye_mid.y - nose_base.y| / lower_face_h   трети (верх-сер/низ)
  eye_to_chin_frac = |eye_mid.y - q[16].y| / face_height      доля низ-лица от глаз
  ioc_over_bizyg = eye_separation / bizygomatic    межзрачковое к ширине лица

=== МЕТРИКИ НОСА (расширение базовых) ===
  nose_length    = ||q[51]-q[60]||          длина носа (radix -> основание)
  nose_bridge_up = ||q[55]-q[65]||          ширина спинки (верх)
  nose_bridge_mid= ||q[56]-q[64]||          ширина спинки (середина)
  nose_alar      = ||q[57]-q[63]||          ширина крыльев
  nose_len_to_face = nose_length / face_height
  nose_wid_to_face = nose_alar / bizygomatic

Примечание: метрики ниже базовых 17 — это ПРЕДЛАГАЕМОЕ расширение (в исходных
файлах папки отсутствуют). Отбор по separability (between/within) и held-out
accuracy — см. .runtime/metric_probe.py; в классификатор morphing включаются только
метрики, улучшающие удержанную точность.
