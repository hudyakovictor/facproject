## 📍 РАСПОЛОЖЕНИЕ ДАННЫХ

```
report/
├── metadata/
│   ├── anatomical_zones.json          ← ОПИСАНИЯ ЗОН И ТОЧЕК (UI + templates)
│   ├── hypothesis_types.json          ← ОПИСАНИЯ ГИПОТЕЗ (UI + templates)
│   ├── metrics_glossary.json          ← ГЛОССАРИЙ МЕТРИК (UI + templates)
│   └── legend.json                    ← ЛЕГЕНДА ДЛЯ ЖУРНАЛИСТА
```

**Почему здесь:**
- `metadata/` — глобальные справочные данные
- Используются и в UI (интерфейс), и в templates (журналист)
- Один источник правды — не дублируется
- Легко обновлять и расширять

## 🎯 КАК ИСПОЛЬЗУЮТСЯ ОПИСАНИЯ

### В интерфейсе (UI):
```
При наведении на точку в UI:
  → Читается из anatomical_zones.json → points.{point_id}.description
  → Показывается tooltip с описанием

При выборе зоны:
  → Читается из anatomical_zones.json → zones.{zone_id}.description
  → Показывается описание зоны

При просмотре гипотезы:
  → Читается из hypothesis_types.json → hypothesis_types.{type}.description
  → Показывается описание гипотезы
```

### В шаблонах для журналиста:
```
При генерации thesis:
  → Для каждой значимой точки:
    → Читается из anatomical_zones.json → points.{point_id}.journalist_phrases.{level}
    → Подставляется в предложение
  
  → Для каждой гипотезы:
    → Читается из hypothesis_types.json → hypothesis_types.{type}.journalist_phrases.{strength}
    → Подставляется в предложение

При генерации zone summary:
  → Читается из anatomical_zones.json → zones.{zone_id}.journalist_note
  → Добавляется как примечание к разделу
```

### Пример генерации:
```
ВХОД:
  point: cheekbone_left, z_score: 4.2, displacement: 2.8mm

ШАБЛОН:
  → anatomical_zones.json → zones.bone_structure.points.cheekbone_left.journalist_phrases.significant_change
  → "Значительное смещение левой скулы ({value} мм, z={z})"

ВЫХОД:
  "Значительное смещение левой скулы (2,8 мм, z=4,2)"

КОНТЕКСТ:
  → anatomical_zones.json → zones.bone_structure.journalist_note
  → "Изменения костных структур — наиболее надёжный индикатор"

ИТОГОВЫЙ ТЕКСТ:
  "Значительное смещение левой скулы (2,8 мм, z=4,2). 
   Костные структуры — наиболее надёжный индикатор, 
   так как кости не меняются от мимики или освещения."
```
